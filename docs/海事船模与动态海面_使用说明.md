## 本轮崩溃修复

1. AirSim 当前源码 `PawnSimApi::createCamerasFromSettings` 会用配置值直接创建相机。缺少 XYZ 或 Pitch/Yaw/Roll 时默认 NaN，产生无效变换并导致后续空对象访问。已为全部自定义相机补齐六个字段，并在启动脚本添加有限数值检查。
2. 自动建图从 Python commandlet 改为完整编辑器的 ExecutePythonScript 模式，避免创建关卡时的访问异常。
3. 编辑器材质桥使用已安装的 MSVC 14.38、单编译进程及独立模块构建，并从本机引擎读取 BuildId 写入模块清单。材质桥只负责连接海面顶点位移，不参与运行时飞行控制。
4. 启动器通过保存的进程 ID、启动时间及可执行文件路径识别自身进程，提供加载进度、超时、退出检查和窗口恢复。
