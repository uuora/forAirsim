# 硕士论文结构与证据映射

更新：2026年10月3日。依据《修改9.29.docx》三项研究及用户确认，当前实验范围仅为AirSim。

目标是完成一篇具有统一问题定义、方法、对照实验和结论的硕士学位论文。平台演示、接口测试、方法实验分别登记；章节结论只能使用与其方法版本对应的实际实验记录。以下是工作结构建议，后续与学校模板和导师意见对齐。

## 建议章节

| 章节 | 主体内容 | 需要的证据 |
|---|---|---|
| 第1章 绪论 | 任务背景、研究问题、相关工作、三项研究之间的关系 | 核验过的文献；搜索范围内的差距分析；不预写“首次”或性能优势 |
| 第2章 建模与仿真平台 | 坐标与时间、感知质量定义、轨迹代价、动力学与安全约束、统一任务裁判 | 模型假设、配置及版本、接口校验、采集与失败台账 |
| 第3章 单机单目标感知任务轨迹优化 | 观测估计、候选预测质量、轨迹选择、执行反馈、失效处理 | 同输入的效率/感知规划对照；身份、遮挡、延迟等消融；实际轨迹和全部已开始回合 |
| 第4章 双机单目标互补感知轨迹优化 | 共享观测、互补视点、联合约束、角色交接 | 双机同步记录、通信扰动、无共享/固定分工/动态互补对照 |
| 第5章 连续刷新气球的协同规划 | 每轮重新感知、分配与快速接触；规则基线和固定奖励学习 | 完整连续会话、刷新与接触裁判、任务吞吐、训练种子与独立测试；不能把相邻轮当独立样本 |
| 第6章 总结与展望 | 回答三项问题、限制和后续研究 | 逐项对应结果；真实部署仅作为未来工作，不作为本轮完成条件 |

## 当前先完成第3章的研究闭环

1. **接口先导**：真实RGB/深度时间戳、相机与机体坐标、实测运动状态、规划到执行的延迟、起降与失败收尾。已知几何输入单独标记oracle。
2. **感知估计先导**：用相同RGB/深度观测分别运行效率与感知规划。可见表面代表点与真实目标中心区分；真值只供布景及独立评估，不替代策略估计。
3. **质量建模**：现有颜色检测提供几何候选，连续帧计数仅是防抖；后续补实例身份关联、置信校准、遮挡与重获评价。YOLO及低频VLX作为单独感知条件，记录额外时间预算。
4. **正式协议冻结**：固定场景种子、对照、终止条件、主要指标、消融及统计独立单位。开题提出每关键工况至少30个独立回合；先导后结合变异和计算预算确定最终规模。
5. **采集与复算**：原始图像/深度、观测及估计、候选代价和拒绝原因、参考轨迹、实际轨迹、执行命令、全部失败和中断均保存。源码或配置改变后另立版本，不能跨版本拼成效果结论。
6. **章稿与结果对齐**：方法实现稳定即可写定义和算法；有实际数据后填写结果；保留无改善、不可行和延迟超预算结果。接口检查通过不等于创新性或效果已验证。
