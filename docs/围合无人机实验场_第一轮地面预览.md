# 围合无人机实验场：第一轮地面预览

本轮按用户要求交付地面场景、实际 Unreal 多视角画面和几何检查。飞行、绕障接近、远距离身份识别评测和双机接替均另行安排。目标气球保持静止。

## 已核对的模型资产与实现方式

已通过本机 UE4.27 Asset Registry 与真实网格加载检查核对资产，原始核查见 `logs/enclosed_lab_asset_inventory_v2_20261008.json`。

| 类别 | 本机资产 | 本轮使用方式 |
|---|---|---|
| 无人机 | AirSim 的 BP_FlyingPawn、QuadRotor1 和 MiniQuadCopter 模型 | 两架实际 SimpleFlight 无人机，由 AirSim 生成并落在平台上；不启用 API 控制 |
| 基础网格 | Engine BasicShapes：Cube、Sphere、Cylinder、Cone、Plane | 主要使用 Cube 与 Sphere；复制到新地图命名空间后重新建立一个明确的盒/球简单碰撞体 |
| 旧场景网格 | Blocks 的方块/地面及此前生成的海事船体、水面网格 | 本轮不使用海事网格；旧地图与资产保留 |
| 日常障碍物 | 当前项目没有现成集装箱、长椅、设备柜或城市模型库 | 用基础网格组合简化的集装箱、箱堆、设备柜、长椅、隔离栏与门架；明确属于组合模型 |

新地图保存为 `/Game/EnclosedUAVLabV1/Maps/EnclosedUAVLab`，可重复通过 `scripts/unreal/build_enclosed_uav_lab.py` 生成。所有新材质、碰撞网格和地图写入 `/Game/EnclosedUAVLabV1`。没有下载第三方模型。

## 场地与任务布局

- 地面：60×36 米。工程坐标范围 X=−6～54 米、Y=−18～18 米，地面顶面 Z=0。
- 四周围墙：3.2 米高，围墙立柱最高3.7米；场地顶部开放，无顶棚。
- 起点平台、目标平台：各6×8×0.6米，中心间距48米。
- 起点：DroneA、DroneB分别位于平台两处 H 标记；本轮均为地面无人机。
- 目标：白色横条红气球，直径2.0米、球心离地3.1米；另有直径1.8米的普通红气球、直径1.6米的黄色气球。
- 障碍：1.2米黄色低块、5.5米紫色高块、3.5米青色中块、3.0米蓝色集装箱组合、2.4米箱堆、3.8米绿色设备柜、1.36米长椅、1.30米隔离栏和最高5.025米的开放门架。

48米是本轮的布局选择，用于落实“距离远一些”；距离是否符合最终实验设计，仍由用户根据预览确认。地面距离标线仅表示尺寸，不代表规划或实测飞行路线。48米距离下的气球可识别性尚未评测。

## 可见模型、碰撞体、规划几何的对应

统一配置为 `configs/enclosed_uav_lab_v1.json`。工程坐标采用米、X向前/Y向右/Z向上。Unreal 中采用厘米，因此生成时统一乘100；AirSim世界 NED 通过已知地面中心的实际读回校准原点，转换关系为 `[X−originX, Y−originY, originZ−Z]`。无人机局部坐标不直接当作地图世界坐标。

每个部件拥有稳定的 `EL1_*` ID。可见网格实例、Unreal 简单碰撞体及导出的规划图元均关联同一个 ID。UE可能给内部Actor名追加编号，因此编辑器报告明确记录 `id → unreal_actor_name` 的一对一映射，运行时按该记录读取，不用模糊匹配猜对象：

- 箱体、围墙、平台、支架等：网格为六面立方体，碰撞为尺寸对应的盒，规划为同尺寸轴对齐包围盒。
- 气球：网格为均匀缩放的球面，碰撞及规划采用同半径的球。可见球面是三角网格，碰撞球是解析曲面，二者表示方法不同。
- 长椅、箱堆、门架：保留各部件的几何并集；不把空隙填成整个物体的大盒子。
- 地面标线、文字、H标记、涂装饰面：明确标为无碰撞、无规划几何。这些装饰可能离实体表面有毫米级偏置，不能当作新的实体障碍。
- 无人机是实验主体，不列入静态障碍清单；未来双机避碰需要另外建立动态机体几何。

`reports/enclosed_uav_lab_v1_20261008/planning_geometry.json` 导出逐部件盒与球图元，`geometry_correspondence.csv` 给出完整对应表。图元尚未接入新地图的运行控制器，也尚未应用机体尺寸与避障净空膨胀。

## 本轮检查与画面

编辑器对134个部件读取可见中心、尺寸与碰撞配置，并逐部件执行六个轴向边界线段和三个边界外线段；查询时隔离其他物体，避免相邻部件混淆结果。碰撞边界允许误差为15毫米，可见尺寸允许误差为5毫米。它是有限的几何抽查，不构成所有接触位置或飞行安全证明。

实际加载后的检查重新读取全部部件的位置、尺度和旋转，并检查两架无人机的落地标志、速度、API控制释放与实际平台接触记录。程序仅创建地面预览，读取图像和状态；没有解锁、起飞或移动无人机/气球的调用。

实际 Scene 相机画面保留原始 PNG 与 SHA-256：

1. `overhead.png`：实际 Unreal 正上方俯视图。
2. `drone_front.png`：实际 DroneA 起点机载前视图。
3. `target_close.png`：实际 Unreal 目标平台近景。
4. `overview.png`、`start_close.png`：场地总览与无人机平台近景。
5. `dimensions.svg` / `dimensions.pdf` / `dimensions.png`：同配置生成的尺寸示意，可编辑矢量输出；不是实际 Unreal 照片，也不是实测航迹。

在 `reports/enclosed_uav_lab_v1_20261008/preview.html` 中可切换视角和筛选几何部件。最终检查状态见该目录的 `acceptance_checks.json`，原始日志及哈希见 `provenance.json`。

复看已交付内容可直接打开HTML；重新生成地面预览可双击 `Run-Enclosed-UAV-Lab-Preview.cmd`。它加载已保存地图、只读采集并打开预览页，完成后仿真暂停。若41453端口已有预览，本入口会拒绝覆盖。需要关闭该预览时，用 `.venv/python.exe python/enclosed_lab_preview.py close --session <该会话的scene_session.json>`，程序先核对所属进程身份和两架无人机的地面状态。后续采集与导出使用新目录，不覆盖本轮封存交付。
