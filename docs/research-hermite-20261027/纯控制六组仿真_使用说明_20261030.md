## 打开和选择

双击 `D:\forAirsim\03_三维双目标控制.cmd`，点击新增加的“六组控制实验：固定 / 随机目标”。也可双击 `D:\forAirsim\打开轨迹实验面板.cmd`。

打开面板、切换方法均不自动连接或飞行。实验实例使用独立端口41461 / ResearchDrone，原03工作台使用41460 / DroneControl，避免相互重置。

1. 下拉选择普通Bézier、普通Hermite、二者基础ABOM版本或二者改进候选。
2. 默认已有固定目标 `(8,0,5)` 米方案，起点 `(0,0,5)` 米。点击“运行所选方法”只执行当前一组。
3. 修改“目标 x,y,高度”，点击“固定目标生成方案”：先在简化模型中生成六组参考；完成后再选择一种飞行。此步骤不会飞行。
4. “生成随机目标”按种子确定新目标。相同种子和代码版本复现同一目标；目标坐标、边界状态及全部候选日志保存为独立方案包。
5. 输入次数，点击“连续测所选方法”：明确启动指定次数的独立测试，启动时冻结方法和递增种子清单，每轮从清单读取，不受中途编辑输入框影响。每轮重置、初始化，不是原03工作台那种不中断的滚动飞行。默认3轮，可选1至30轮。
6. “本次后停止”取消后续轮次，包括排队但尚未开始的方案生成；已开始的任务保存完毕。若当前仅在生成方案，方案完成后不再启动飞行。没有连续任务时，点击停止不会改写已完成记录。
7. 勾选同一目标方案、同一协议的历史记录，点击“比较选中结果”。重复运行保留；不同目标/控制器/协议等条件会显示差异并拒绝混合排名。
8. “重跑选中记录”使用该记录的冻结配置和完整原始方案，适用于复核或重跑失败记录。

关闭面板停止后续调度。当前独立子进程输出直接写文件，可能继续完成；不会自动恢复未执行轮次。重新打开后可刷新已保存记录。

AirSim主视口：青色为参考轨迹，橙色为实际轨迹，黄色为端点标记；红球为终点，蓝球为起点。显示的是位置轨迹，不是姿态轨迹或电机信号。目标球是静态标记，全程没有交互，也不提供任何感知输入：控制器直接读取方案文件里的目标坐标。

相机截图（`visualization.capture_overview`）自2026-10-30起关闭。它不进入控制回路，`audit_airsim_curve_replay_pilot.py` 与 `compare_airsim_curve_runs.py` 也不读取它；位置证据以 `states.csv`、`trace.json`、`report.json` 为准。该开关属于 `visualization` 块，不在对比器的条件指纹内，因此关闭前后的记录仍可直接混比。

运行位于 `reports/airsim_selected_时间戳/`，启动器日志为同名 `.launcher.log`。其中 `replay/` 包含：

- `方法/trace.json`、`states.csv`、`events.jsonl`：原始状态时间戳、同步参考、实际状态、指令及事件。

## 当前控制协议及证据边界

当前默认协议12，使用静止到静止的端状态，两端速度、加速度均为零。普通参考是五次基线；加入三维形变后至多六次，四个搜索参数为三维形变和执行时长，时长范围3至7秒。Bézier/Hermite使用相同物理参数域，可以表示同一条曲线。协议12在协议11上增加初始加速度读回核验（0.05m/s²）及估计加速度/角速度日志，未改变控制器和原误差门槛。

AirSim统一外环：`c_raw = qdot + 2(q-p) + 0.8(qdot-v) + 0.9 qddot`，再限制速度指令范数4m/s与变化率4m/s²。0.9秒前馈系数在独立开发标定中从预先列出的0.3/0.6/0.9秒网格选择；它不是已证实的电机或机体时间常数。六组共用冻结控制器。

实际参考时钟由AirSim状态时间戳推进。步进请求0.02秒，允许状态间隔上限0.10秒；终点按包围T的实际状态插值。原门槛保持：峰值位置误差0.5m、终端位置0.25m、终端速度0.5m/s。初始化包含固定升空准备和仿真专用初态注入，不能解释成真实起飞实验。

优化在一阶滞后质点模型中进行，再将冻结参考交给AirSim执行。当前规划模型已使用同一外环公式和0.9秒有效滞后，但仍不能表达AirSim完整动态；协议10的旧规划模型和结果单独保留。每个优化组80次候选、额外一次完整验证；普通组一次验证。全部六组生成共326次完整模型调用，AirSim搜索调用为0。常驻规划进程仅复用导入环境，每轮重新初始化网络、重新评价全部候选，不复用权重或目标值。首次启动和IPC计入父进程总规划墙钟时间。等候选数不能证明墙钟提效。

最新固定目标六组对比：`reports/control_targets_fixed_v12_comparison/`；原始数据：`reports/airsim_control_targets_v12_fixed_six/`；分量图：`reports/control_targets_v12_figures_components/`。六组均通过原门槛，优化组执行更快但误差更高，综合评分没有优于普通基线。旧协议和随机目标记录分别保留。均属开发/小样本验证，不能声明算法普遍优越、真实飞行可靠或高敏捷性已充分验证。

模型资源诊断：`reports/control_resource_diagnostics_20261030_v1/`。36次父进程截止试验、72次软截止诊断和9个筛选配对均保留；筛选仅节省10/720次完整模型调用，热计时中位数反而增加，未设为默认。

## 离线准备与命令行
