# 初始曲线参数扰动：复现实验

日期：2026-10-27。以下命令从仓库根目录执行，使用任意新输出目录。实验只计算多项式点参考、障碍几何和参考导数约束，不需要 AirSim、Unreal、GPU 或飞行器连接。主实验包含四维单形变与七维双形变、三个固定开发布局、七种搜索器和20个优化器种子。每次运行256个训练候选，共840次优化运行、215,040次训练候选评价。

## 环境与上游网络

创建并激活独立 Python 环境后安装依赖：

```text
python -m pip install numpy matplotlib torch
```

实际实验环境为 Windows、Python 3.10.21、NumPy 1.26.4、Matplotlib 3.10.9、PyTorch 2.11.0+cu128。ABOM适配器在 CPU 上运行，未使用 CUDA 计算。CPU 版 PyTorch 可执行相同接口；本项目没有据此承诺跨版本、平台或浮点库逐位一致。需要尽量匹配本轮环境时，可在适用的 Python 环境中指定：

```text
python -m pip install numpy==1.26.4 matplotlib==3.10.9 torch==2.11.0
```

安装命令依赖包索引对当前 Python/平台提供相应构建，`+cu128`构建标签不是本研究的GPU要求。

ABOM网络源码来自[作者官方仓库](https://github.com/xiaofangxd/ABOM)，固定提交 `79a2baec700ce0abc6cf7d4cba1e897989d80516`。仓库不附带该第三方网络源码；准备脚本只下载所需的 `abom_net.py`，放入被Git忽略的临时目录：

```text
python scripts/prepare_abom_research.py
python scripts/prepare_abom_research.py --check-only
```

下载与现有文件均须通过Git blob SHA-1 `5959aa7e4aef13c6b128e7c16e51d8a23205d030`。脚本先核验下载字节再写入，每次网络请求设20秒超时，最多三次；出现网络故障或哈希不符会显式失败。已有不符文件会被拒绝，不会被替换。`--check-only`仅做离线核验。自定义目录示例：

```text
python scripts/prepare_abom_research.py --destination tmp/my_abom_source
```

此时训练命令还应加入 `--upstream tmp/my_abom_source`。相对下载目录按仓库根目录解析。上游网络只依赖NumPy、PyTorch与Python标准库；此处没有使用MetaBox或上游完整优化器。适配器包含共同初始化、归一化域、固定评价预算等本研究设置，不能称为ABOM论文结果复现。

## Linux 或 macOS

```bash
export PYTHONPATH="$PWD/python"
python python/run_parameter_perturbation_research.py train --output reports/parameter_perturbation_reproduction
python python/run_parameter_perturbation_research.py validate --output reports/parameter_perturbation_reproduction
python python/run_parameter_perturbation_research.py summarize --output reports/parameter_perturbation_reproduction
```

默认值为：`--families single_bump paired_bump`，布局 `central early_offset two_obstacles`，搜索器 `random gaussian de jde coordinate abom abom_perturb`，优化器种子100至119，种群16，预算256。每个固定布局分别优化，所有方法使用相同端状态、约束、代价和同种子初始种群。双形变新增自由度与单形变维数不同，二者共享相同函数评价预算，不能假定有限预算下高维搜索必然更好。

`validate`在训练所选参数全部冻结后产生每个布局64个误差包络内的障碍条件。默认压力种子 `20261101`，按manifest中的布局顺序分别加0、1、2；优化器种子与压力种子用途不同。同一布局的所有方法、两个曲线自由度及其初始参考均接受相同压力场景。包括六个初始参考在内，共846条参考、54,144次验证条件评价。一个双障碍场景仍计为一次条件评价，其几何计算成本高于单障碍场景；优化评价数与耗时分别报告。

压力场景用于核查声明包络内的实现表现，不是未见布局泛化试验，也不是独立飞行重复。默认中心误差椭球为 `diag(0.30,0.05,0.05)` m，障碍半径在名义值上下0.05 m内变化；这些边界为离线设定，未由真实感知残差标定。训练约束包含半径正增量0.05 m和点参考净空0.1 m。

## 快速检查与非神经对照

小规模真实运行可先确认环境与证据链：

```text
python python/run_parameter_perturbation_research.py train --output reports/parameter_perturbation_smoke --families single_bump --layouts central --methods random de jde coordinate --seeds 3 --budget 32 --stress-count 2
python python/run_parameter_perturbation_research.py validate --output reports/parameter_perturbation_smoke
python python/run_parameter_perturbation_research.py summarize --output reports/parameter_perturbation_smoke
```

这组命令不需要上游网络或PyTorch调用，包含4次优化运行、128次训练评价与10次验证条件评价。它只确认程序可用，不替代主实验。

本轮新模块的数学、搜索和缓存回归：

```text
python -m unittest test_research_parameterizations test_research_blackbox test_research_perturbation_task test_research_parameter_campaign
```

这些测试使用 `PYTHONPATH` 所指向的本仓库 `python/`，不启动飞行仿真。缓存测试中的曲线评价和黑箱搜索均为真实小规模执行；仅以一个来源fixture隔离并发开发对源码快照的影响。

## 读取保存证据与重跑的区别

公开证据目录为[experiments/hermite_perturbation_20261027](../../experiments/hermite_perturbation_20261027)。其中 `previous_round_evidence.zip`保存上一轮原始记录，`new_round_evidence.zip`保存本轮原始记录；摘要、清单及哈希用于定位归档内容。请先按该目录的证据清单核对压缩包哈希，再解压到独立目录读取。

每组实验的 `manifest.json`声明设计及源码哈希；`source_snapshot/`保存当时源码；`train/`保存每个候选及历史；`selection.json`固定训练最优解；`stress_cases.json`固定压力场景；`validation/`保存每条参考的完整验证；`validation_summary.json`与`summary.json`分别绑定证据及汇总。旧版实验的文件名、字段和绑定完整性不同，应使用各自归档的清单与核查结果，不能把新协议倒填到旧记录。

当前训练命令只允许恢复与当前源码和设计完全相符的缓存。源码、选定参数、设计或摘要有变化时，程序拒绝静默覆盖，应换一个输出目录重新运行。历史结果需要重新计算时，应使用其冻结源码、当时依赖版本和独立输出目录；仅把旧 `train/`复制到当前runner下，不能构成复现。核对现存记录与重新执行实验是两种操作，哈希一致也不能证明运行时间或真实执行顺序。

上一轮 `search_pilot`含明确标出的历史未绑定字段；早期退役椭球名义组也保留在归档中，不纳入正式对照总数。应保留这些记录，不能据新runner的严格校验回写历史文件。新的数学或数值修订同样应另建实验目录，并说明替代关系。
