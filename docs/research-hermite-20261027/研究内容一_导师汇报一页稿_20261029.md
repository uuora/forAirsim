# 研究内容一控制仿真实验：导师汇报稿

2026-10-29｜E0最小验证已完成；优化器正式对比与AirSim验证为后续计划

**实验题目：固定跟踪控制器下，学习辅助黑箱搜索的无人机轨迹优化与计算效率验证。**

本实验围绕开题报告研究内容一开展。给定无人机起终位置、速度及环境约束，利用 Bézier/Hermite 表达参考轨迹；固定底层跟踪控制器，仅优化轨迹形状参数和执行时长。通过闭环仿真获得跟踪误差与约束信息，再由 ABOM 筛选候选并更新搜索网络。

研究问题是：在保持可执行性和跟踪精度的前提下，能否减少规划计算时间及昂贵的闭环仿真调用？规划计算时间与飞行执行时长分别记录。

**系统：曲线参数 → 时序参考轨迹 → 固定控制器 → 仿真无人机 → 执行评价 → ABOM 更新。**

| 实验 | 对照及设置 | 要证明什么 |
|---|---|---|
| 控制接口核验 | 直线、绕行、高度变化；每种缓/快两档；无优化器 | 参考与实际状态按同一时间对齐，控制和日志正确 |
| 闭环评价实验 | 初始参考、几何目标优化、加入执行误差的优化 | 闭环反馈是否改善实际跟踪 |
| 核心效率实验 | 随机、高斯、坐标、校准 ABOM、改进 ABOM；同硬件和预算 | 相同计算时间内是否获得更好的可行轨迹 |
| 消融实验 | 基础方法、仅筛选、仅反馈、完整方法；必要时加零/打乱特征 | 提效是否来自所提出的机制 |
| 鲁棒性与 AirSim | 固定优化结果，改变初态/模型响应，再以固定配置在 AirSim 执行 | 结果能否在扰动和更完整仿真中保持有效 |

第一阶段复用现有三维一阶滞后质点模型和固定速度跟踪器，搜索四维参数：三维形状扰动与执行时长。正式主实验拟用 3 类新场景、每类 2 档难度、20 个配对种子、5 种搜索：墙钟实验 600 次并读取三个预算截点，等候选实验另 600 次；若策略依赖终止预算，则墙钟部分需三个预算各 600 次。先完成小规模接口先导，再扩展正式规模。已有场景只作为开发集，正式场景与参数在运行前冻结。

核心指标为预算截止时的可行率与最佳轨迹质量，辅以规划墙钟时间、完整仿真次数、网络开销、参考执行时长、同步位置 RMSE、峰值与终端误差、实际净空及指令限幅比例。初始轨迹已可行时，不使用“首次可行时间”证明搜索更快；失败和超时全部保留。

Bézier 与 Hermite 先做同次数、同边界、同自由度的表达核验；可以相互变换的同一轨迹不能作为两种方法优劣的证据。主贡献应来自可检验的搜索或评价机制。

现阶段已完成24次简化闭环执行及独立核查：三种参考×两档时长×四条件。5.5秒的12个工况均通过误差门槛，3秒的12个均未通过；快速工况出现明显指令限幅。这些是控制接口的正负样例，尚不能证明优化算法优势。下一步补统一三维 AirSim 执行器和公平墙钟预算测试。现有诊断反馈分支尚无稳定优势，依据消融结果决定是否保留。
