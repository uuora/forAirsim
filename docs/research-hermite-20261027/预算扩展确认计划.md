# 黑箱参数扰动的预算扩展计划

2026-10-27。本计划在主实验完成前记录；目前已查看主实验六次空间 `central` 布局的训练均值，尚未查看主实验完整验证结果。因而本计划是开发后的确认与预算敏感性分析，不是盲于所有开发结果的预注册。

固定七次空间 `paired_bump` 和三个既有布局，不调整参数盒、初始曲线、目标、约束、表示或证书。继续比较 `gaussian`、`jde`、`coordinate`、`abom`、`abom_perturb`，使用新的优化器种子200–219，每次512次评价，种群16，共300次运行、153,600次候选评价。选择仍只使用训练目标。压力场景采用新种子20261111起，每个布局64个包络内条件，在全部选择冻结后生成。

主要问题是：局部结构化扰动相对ABOM适配器的训练质量收益，在新随机初始化及更大预算下是否保持；ABOM加入扰动后的变化，是否仍超过简单高斯和坐标搜索；七次空间的预算不足，能否解释主实验中的表现。512次轨迹中的128、256和512次前缀仅作预算敏感性分析，不把三个前缀作为独立运行。

报告各布局的质量、参考时长、jerk积分、全部压力条件通过数以及配对种子差异。保留所有失败、跨零区间和负结果。20个优化器种子仅衡量固定布局下的随机性；新压力场景仍位于相同人为设置的几何误差包络中，不代表新布局、真实感知或飞行泛化。

主实验与扩展实验顺序执行以减少相互CPU竞争；墙钟耗时仍受本机负载影响。分析脚本、完整manifest、源码快照、候选日志、冻结选择与验证将随结果公开。AI协助方案、实现、检查和报告。
