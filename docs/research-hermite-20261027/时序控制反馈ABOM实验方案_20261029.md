# 时序控制诊断反馈的ABOM实验方案

日期：2026-10-29。状态：先导运行前固定方案，不是实验结论。AI辅助完成方法讨论与实现。

## 研究问题

在相同端状态保持参数域、初始化、候选预算与固定跟踪控制器下，将同一次执行已经产生的跟踪诊断加入ABOM候选生成，能否改善最终可行解质量，且其额外计算是否值得？这是待检验假设，不预设网络必须胜出。

现有生产RollingController为路径跟随器，不提供同步q(t)接口。本实验另用明确标识的独立点质量研究模块，不与生产控制器或AirSim实飞结果混同。[接口](../../python/trajectory_research/timed_tracking.py)

## 固定模型和评价

在实际时间[0,T]内使用q(t)、qdot(t)，不追加终端悬停。固定控制器为速度前馈加位置反馈，位置增益2 s⁻¹；速度指令上限4 m/s，指令变化率上限4 m/s²。植物为位置导数等于速度、速度向指令以时间常数tau一阶滞后，用零阶保持指数闭式积分。训练tau=0.30 s，步长上限0.02 s；选定参考后另在tau=0.15、0.45 s检查，不将这些结果用于搜索。

沿用4/7维端状态保持参数域和三个既有开发布局。目标固定为：

Q = 0.7 T/(T+5) + 0.1 J/(J+30) + 0.2 RMSE/(RMSE+0.25)。

RMSE为同步位置误差平方的梯形积分除以T后开方；J为参考jerk平方积分。可行候选分数为Q，不可行为1+失败检查占比+Q。判据为既有参考检查、采样峰值误差≤0.5 m、终端位置误差≤0.25 m、终端速度误差≤0.5 m/s，以及模型内实际点轨迹的名义障碍净空和工作空间检查。实际轨迹采用速度上界乘采样间隔一半的保守间隙；该判据仅适用当前模型与静态名义球障碍。参考的几何误差包络不自动转成跟踪轨迹的鲁棒保证。

这些阈值是运行前固定的研究判据，不是飞行标准；不根据先导结果回调阈值制造通过或失败。

## 反馈与对照

网络反馈为归一化排名和五项诊断：RMSE/0.25、峰值误差/0.5、终端速度误差/0.5（前三项截断至4）、指令变化率限幅时间比例、峰值误差归一化时间。诊断由同一次rollout提取，不增加目标调用，计算耗时仍计入总体。

比较六种设置：

1. scalar：一维归一化排名的ABOM适配器。
2. diagnostic：排名加五维诊断。
3. zero：与diagnostic同容量，但诊断置零。
4. shuffled：同容量，诊断在父代内打乱，排名保持正确。
5. 高斯搜索。
6. 坐标搜索。

diagnostic、zero和shuffled具有相同网络初始化及参数量，区分诊断信息与容量作用。所有神经设置dropout先固定0.1，沿用每代源式精英学习；它来自几何开发集的校准候选，尚未证明适合控制任务。排名统一映射至[0,1]，与原适配器的未归一化排名不同，必须披露。全部设置共用评价器，记录失败样本、诊断、源评价ID及消费的特征矩阵。

## 先导与后续

首轮只做接口与实验流程先导：四维、中部布局、种子590和591、64候选、种群16、六种设置，共12次搜索。执行顺序在运行前固定并交错。此规模不能确认方法优势。若核查通过，再在新种子与其他布局扩展，不以先导最优种子筛选主实验。
