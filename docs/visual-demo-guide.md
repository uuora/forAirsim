# 视觉对准与测距停止演示

双击项目根目录的 `Run-Visual-Range.cmd`。程序会打开 Blocks（若尚未运行）、恢复气球、检查双机地面状态并启动测试。UE 打开但 RPC 未就绪时，需进入 Play。

你会看到：两机起飞 → B 到待命点 → A 到观察点 → A 根据画面左右/上下调整 → A 低速前进 → 测距约2.5m时停止前进并完成居中 → 两机返回降落 → 仿真暂停。

这是不接触气球的视觉演示。不要把“停止距离”理解为飞机中心到气球中心的距离：记录的是深度相机目标框内表面的估计距离。

## 看结果

在 `logs/mission_visual_range_日期_时间/` 内查看：

- `report.json`：`status=PASS`、`alignment_verified=true`、`range_stop_verified=true`、`landing_verified=true`，以及两机 API 控制释放记录。
- `align_*.png`：逐帧气球检测框。
- `samples`：图像误差、深度、速度建议、机体姿态及坐标。
- `telemetry.jsonl`：任务阶段、位置、速度和双机间距。

若失败，程序暂停仿真并保存现场；不要直接重新双击启动。先检查异常与空中状态，再执行经过检查的回收流程。

## 控制原理与范围

前视相机中的气球偏右就向右调整、偏左就向左调整；垂直误差缓慢调整高度设定值。图像基本居中时才允许最高0.15m/s前进。到达距离阈值后禁止继续前进，但保留横向与垂向小幅调整，避免“距离已到但尚未居中”导致流程卡住。

此版本使用固定准备航点、仿真高度反馈与空间边界，属于混合视觉控制。尚不覆盖动态气球、遮挡后的搜索、复杂障碍规避、视觉接触以及双机视觉补位；现有离线测试和少量仿真通过也不代表这些能力已验收。
