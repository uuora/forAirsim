# 硕士论文图表规范

自2026年10月5日起，后续研究图表优先使用中文标题、坐标轴、图例、状态说明和图注。方法名称、版本编号、单位及YOLO、VLX等通用缩写可以保留；程序内部状态码放入数据表或复现记录。

科学图表按以下口径制作：

- 时间轴写明起点与单位；区分初始获取、主测量、遮挡及返回阶段。
- 原运行器判定与独立身份、执行核验分别呈现。
- 展示无输出、错误目标、漏采与失败，注明评价分母。
- 使用可覆盖中文字符的字体，保存PNG和PDF，并检查文字、图例和边界。
- 保存绘图源码、输入数据、字体及输出文件的哈希。封存图表保留原版；中文重绘作为同一数据的新呈现，不作为新试验。
- 试验版本或负载不同的曲线可以并列展示，方法收益结论须由正式共同条件比较支持。

图注解释可见现象和测量范围。开发点标签不写成连续身份保证，采样时序不写成硬实时证明，测试数量不写成算法效果。

AI协助说明：此规范按作者提出的中文图表偏好整理，最终论文排版仍按学校要求统一。
