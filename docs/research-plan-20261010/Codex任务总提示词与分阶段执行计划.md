## 1. 本次确认的任务

用户希望形成如下链路：

```text
中文自然语言指令
  → 语言模型解析为结构化任务
  → 程序验证任务及当前能力
  → AirSim 机载 RGB
  → 本地 YOLO 检测人、汽车等常见目标
  → 目标框、中心像素位置、目标选择及新鲜度判断
  → 本地任务执行器和反馈控制器
  → 持续观测、修正、完成或停止
```

第一层交付是“识别常见目标并返回图像像素位置”，无需 VLX。第二层才是无人机依据视觉反馈执行任务。优先以“指定目标保持在图像中央”为最小闭环；用像素定位不能直接证明目标世界坐标、距离或已经靠近至某个距离。

如当前图像没有目标，第一版应明确返回未检测到，不自动扩展成未知区域搜索。多个人或多辆车同时出现且描述不能唯一选择时，应澄清或返回候选，不默认把最高置信度当作用户指定实例。持续锁定同一实例与逐帧检测属于不同能力。

暂以 DroneA 单机为新增任务范围，DroneB 保持原有待命约束。用户本轮没有要求恢复双机实验、改变冻结地图或训练大模型。原气球实验保留为独立场景和既有研究证据；人/车检测作为新增能力配置，不静默替换原气球主线。
