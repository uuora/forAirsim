# 固定地图任务执行接口

启动入口：双击 `D:\forAirsim\01_固定地图实验.cmd`。它会核对快照哈希，必要时自动启动 Unreal 固定地图（后台运行，端口 41454），等待服务就绪，再打开人工界面。已有会话必须通过地图、工程和 settings 路径核验。界面显示 READY 后可点击“开始”；启动界面不会自动起飞。已有窗口可用 Alt+Tab 查找“固定地图单机绕障接近 · 人工任务界面”。

控制器：`python/fixed_map_mission.py` 的 `Executor.submit_task(task, actor)` 和 `Executor.command(action, actor)`。人工界面、后续视觉适配器和 LLM 适配器应调用同一入口；各适配器不得直接获取 AirSim 控制或发出运动命令。

当前任务契约见 `reports/fixed_map_flight_20261009/fixed_version/task.json`。本次只接受与经核查任务完全相同的参数。新目标、地图、阈值或来源必须重新验证，当前执行器会明确拒绝变化，不会让模型生成的指令绕过几何检查。

支持动作：`start`、`pause`、`resume`、`stop`、`return`。`pause` 与 `stop` 均取消旧任务并请求实际悬停；`pause` 可以继续，`stop` 要完成悬停记录后返航。返航从实际位置重新规划，到原起飞位置垂直降落，确认平台接触与稳定后关闭解锁并释放控制。

只有执行器线程使用控制 RPC。相机使用独立只读客户端，避免采图阻塞实际状态反馈。界面关闭时若仍在空中，会请求悬停并阻止直接关闭。发生失败时停止推进、保存原因，悬停 RPC 失败也单独记载。

2026-10-09 后续界面修订：Unreal 总览位于左上主显示区，DroneA 前视位于右上，世界坐标与实际状态位于下方。相机通过独立只读 AirSim 客户端取实际图像；总览0.5 Hz，机载默认0.5 Hz，可选1/2 Hz或关闭。原始分辨率仍取自固定 settings（1800×1100总览、1600×900前视），界面缩放不等于降低原始渲染负载。每帧记录取图耗时和UTC时间；超时/过期不冒充实时图像。可用物理内存或Windows提交余量不足1 GiB时暂停新增采集。

文字输入接入本机 Ollama。默认 `fixed-mission-qwen3:0.6b` 来自本机已有、官方哈希已核对的 Qwen3-0.6B-Q8_0 GGUF，CPU两线程、按需推理、结束卸载模型。原有 `qwen2.5:3b` 也可调用，但本轮CPU推理慢且联合资源测试曾发生UE内存不足崩溃，未作为默认。输入文字通过 `/api/chat` 和 JSON schema 返回解析结果。只解析单条固定任务动作；不接受自由坐标、不同高度/速度、DroneB或未知目标。解析本身不启动飞机，核对预览后点击“确认执行解析结果”，才调用同一个提交/命令入口（来源 `llm_preview_confirmed`）。输入变化、任务哈希变化和不匹配的实际阶段会拒绝执行。物理内存或Windows提交余量不足2 GiB时拒绝加载小模型（3B要求4 GiB）。所有原始模型输出、延迟、校验结果和确认提交事件在 interface_revision_20261009/session_* 保存。

渲染稳定性修订：新启动会话通过运行时命令 `r.SceneRenderTargetResizeMethod=2` 保留较大渲染目标，减少总览/前视/游戏窗口之间反复调整尺寸。没有修改地图、资产或冻结的 settings；运行时覆盖值写入新scene会话回执。旧崩溃与各模型误判仍保留，文字语义可靠性及最新界面空中压力测试未通过这些地面检查自动获得证明。

视觉识别与 DroneB 空中任务仍未接入此界面。VLX接口用于既有视觉工作，本次机载画面只显示实际相机图像；文字解析用Qwen，不会把相机视频逐帧送给文字模型。文字分类的准确率和最新界面空中负载还需要专项验证。

重新使用时：先检查地图与快照哈希一致，启动同一 Blocks 地图和快照 settings；地图有变动就产生新的固定版本并重新审计。当前会话可以保留在地面，界面独立关闭后重新启动。禁止借助 reset、teleport 或 simSetVehiclePose 伪造起点与实际飞行。

参数与证据类别：配置值写入 task；实测值为 AirSim 的动力学位姿和速度（仿真测量，非实体无人机）；计算值为目标误差、路径偏差、以及外接球与固定 OBB/球体之间的保守净空。外接球接触平台时的负值必须保留并说明起降接触豁免，不得当作零净空修改数据。
