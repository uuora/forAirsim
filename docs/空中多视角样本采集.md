# 空中多视角样本采集

## 运行

双击项目根目录的 `Collect-Air-Multiview.cmd`，或在项目根目录执行：

```powershell
.venv\python.exe python\collect_air_multiview.py
```

条件会话使用显式场景参数，例如低太阳采集：

```powershell
.venv\python.exe python\collect_air_multiview.py --scenario low_sun
```

场景参数会在起飞前应用，采集器会保存 `experiment.json` 和配置副本，并在两机落地、释放 API 控制后恢复 `baseline`。恢复失败会使整轮报告失败。

采集器要求两架无人机从甲板停机状态开始。`rear_low_v2` 构图配置依次访问五个局部 NED 悬停点：后移 2 米的中、左、右低位观察点，后移 3.5 米的远中观察点，以及后移 1.5 米的近中观察点。高度指令为 3.5--4.5 米，目的是让近处的 `balloon_003` 和船体都完整留在画面内。两机使用相同局部偏移，保留初始 4 米间距。SimpleFlight 的到点验收容差为 0.70 米；同时要求速度低于 0.05 米/秒并连续稳定 2 秒，报告保存每个点的实际稳定位置。每个观察点还要求四个注册目标全部返回，建议框距任一图像边界至少 10 像素。结束时，两机先返回各自起飞点正上方，再降落、解除武装并释放 API 控制。

## 输出

每次运行创建独立的 `logs/air_multiview_时间/`，并更新 `logs/air_multiview_latest.json`。目录包含：

- `report.json`：整轮状态、位姿、测距、图像质量和安全恢复证据；
- `multiview_contact_sheet.jpg`：五个位置、两架无人机的目标框拼图；
- `manual_box_review.csv`：需要人工填写 `review_decision` 和 `review_notes` 的建议框复核表；
- 每个观察点的 `cameras/*_rgb.png`、`*_depth_planar_m.npy`、预览图、传感器样本和 `waypoint_report.json`。

## 使用边界

AirSim 可见性框只是人工复核辅助，不是已经批准的 YOLO 标签。`DepthPlanar` 是模拟器光轴深度，也不是双目算法输出。两机通过独立 RPC 顺序采集，报告中的跨机时间差必须保留，不能把这些图像描述为同步双目数据。
