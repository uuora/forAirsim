# 海事场景传感器：2026-09-15 修复与验收

本轮只解决海事场景的传感器配置、读取、时间进展检查和相机元数据问题。未执行起飞、目标接近或实机控制，也未训练模型。论文主线遵循《海上搜救Agent_平台与研究范围决策.md》；下列传感器作为观测来源，不自动构成方法贡献。

## 使用

双击项目根目录 `Check-Maritime-Sensors.cmd`。它启动海事场景并读取约8秒传感器，随后保存两机各3组RGB/DepthPlanar样本。报告路径打印在窗口中。

```powershell
# 只验收六类传感器
.venv\python.exe python\check_onboard_sensors.py
# 同时保存相机样本
.venv\python.exe python\check_onboard_sensors.py --cameras
# 旧 Blocks 配置必须显式指定，端口由配置读取
.venv\python.exe python\check_onboard_sensors.py --settings configs\settings.json
```

`--settings` 默认为海事配置。检查脚本拒绝配置与运行实例不一致、传感器缺失、时间戳不推进或回退等情况，不会为了通过而自动换成其他传感器。场景需处于运行而非暂停状态。

## 读数怎么理解

| 数据 | 单位/坐标与限制 |
|---|---|
| RGB | 1280×720，Scene投影水平70°；原始图无标框 |
| DepthPlanar | 仿真渲染器提供的光轴深度（米），不是双目估计，也不是沿每条射线的欧氏距离；远景/天空可出现65504，不视为可靠有限物体距离 |
| IMU | 四元数wxyz，姿态参考NED；角速度rad/s，加速度计为机体系比力m/s²，水平静止时z约−9.8，不是应为零的世界系运动加速度 |
| 气压计 | 压力Pa、QNH hPa；altitude是仿真高度参考，不能当距甲板高度 |
| GPS | 经纬度deg、高度m、速度NED m/s；fix/eph/epv为仿真字段，不代表实机GPS精度已验证 |
| 磁力计 | 机体系磁场，AirSim源码单位Gauss（不是Tesla） |
| 前视测距 | 0.2–20m，机体前方；读数在上限附近时可能无命中，不能等同目标距离 |
| 下视测距 | 0.2–10m，向下；停机位离甲板太近，易低于最小量程或因噪声成为负值 |

当前AirSim源码在射线结果后叠加σ=0.2m高斯噪声，未钳制到量程。保留负数并标 `negative_invalid`，不填零；对于距离上限0.6m以内的读数，保守标 `no_hit_or_near_limit`。0.6m是该噪声模型的3σ工程边界，**不是实测标定或命中保证**。只在valid、fresh和in_range均满足时才可作为候选距离，仍不能据此确认它测到指定目标。极端负数/非有限值等仍可使验收FAIL。

范围状态为LIMITED时，脚本退出码可为0，含义是检查完成且无接口/时间进展故障；下游若要求有效距离，必须读取各传感器状态及原始valid/in_range字段，不能只检查进程退出码。

## 时间与几何未解决的部分

- 同一RPC返回的RGB/DepthPlanar时间戳本轮差约3–6毫秒。时间戳来自渲染结果处理，不能将其直接等同实机曝光时刻。
- 两机RGB仍顺序采集；加入深度后的诊断流程本轮相差216–291毫秒。普通仅RGB采集耗时不同，不能混用两种流程的时差。
- 六类传感器序列与相机诊断分阶段执行，未实现IMU/RGB/GPS共同时间同步或传感器融合。watchdog只看时间戳进展，不证明绝对观测年龄或原生采样频率。
- 静止全局原点换算只用于仿真参考。偏移量在本轮读取，不应硬编码用于实机；两机动态外参估计、镜头标定、极线校正、匹配和双目深度尚未完成。
- 相机姿态采用前/右/下轴；OpenCV光学坐标为右/下/前。后续几何计算须明确转换。
- 画面仍有停机位甲板遮挡。本轮传感器检查没有改变观察位置；该限制影响训练图像与目标测距，不能通过“接口正常”消除。

## 实现来源

- 本地AirSim `PIPCamera.cpp:getCameraInfo/getProjectionMatrix`：viewer FOV与Scene投影取自不同组件。
- `NedTransform.cpp:toLocalNed/toGlobalNed`：两者坐标原点不同。
- `DistanceSimple.hpp:getOutputInternal`、`DistanceSimpleParams.hpp`：距离噪声与量程元数据。
- `ImuSimple.hpp`、`MagnetometerBase.hpp`：比力与磁场单位。

AI辅助实现和整理；以上是本地静止仿真验收结果，不是实机传感器标定、定位精度或论文创新性证明。
