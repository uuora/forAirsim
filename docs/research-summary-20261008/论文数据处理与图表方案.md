## 1. 保留四层材料

| 层次 | 内容 | 处理原则 |
|---|---|---|
| 原始记录 | RGB、深度、分割评分、状态、命令、回复、异常与终态 | 原文件保留；以哈希绑定配置、权重、源码和原始输入 |
| 规范数据 | 会话表、帧表、指令表、语义请求表、训练种子表 | 单位、时钟、主键、阶段和缺失原因明确；不把未知补成0 |
| 分析数据 | 会话指标、配对差值、分层分布和评价分母 | 按冻结规则计算；原运行器判断与独立核查分别存列 |
| 论文图表 | 点图、分布图、轨迹图、训练曲线和最终汇总表 | 每个图点可回到输入记录；图注写样本单位、范围与版本 |

已有日志保持现状，新规范表作为派生副本保存，避免改写封存证据。本轮新版示例见[论文科研图与数据目录](论文科研图新版说明.md)，历史CSV见[旧版数据索引](图件索引与论文图注.md)。

## 2. 后续建议固定的数据字段

以下为正式实验前需要冻结的字段方案，当前不是全项目统一迁移已经完成的声明。

| 表 | 主键 | 主要字段 |
|---|---|---|
| 会话表 | campaign_id + session_id | 任务、方法、消融、源码/权重/配置哈希、场景种子、配对编号、车辆、时间、计划/开始/完整主帧、启动/飞行/终态、失败原因 |
| 帧表 | session_id + phase_id + frame_id | 槽编号、源图时钟、采集完成、图像哈希、YOLO候选、选中实例、独立身份状态、源属性、可见面积、中心误差、深度、姿态、处理完成、各时效判定 |
| 指令表 | session_id + command_id | 绑定源帧、目标版本、目标/自状态反馈/零指令类别、实际派发、租约期限、首次目标清零、收尾清零、停止证明、速度与位置 |
| 语义表 | session_id + request_id | 源帧、实际发送/返回、超时、耗时、源图年龄、属性核验、采用/拒绝/过期及原因 |
| 学习表 | training_run_id + seed + step | 模型版本、环境步数、奖励、独立评估结果、checkpoint、固定测试场景、训练/验证/测试角色 |

时钟名与单位进入列名，例如`host_dispatch_monotonic_s`、`image_timestamp_ns`、`net_xy_mm`；不能将主机单调时间直接与仿真绝对时间相减。数据表保留原始秒值，绘图时才换算毫秒。[项目时钟与清零依据](../research-plan-20261004/任务一控制进程与采集中断复验结果.md)

## 3. 清理与统计规则

1. 检查主键重复、媒体/配置哈希、帧槽是否完整、所引用事件是否存在；删除重复只能依据重复主键与内容并留处理记录。
2. 初始化、主测量、遮挡、返回、停止、起降分阶段；任务航程与端点是否包含尾段按预声明执行。
3. 未运行、未起飞、中断、输出未知、无目标输出、错误目标、缺终态分开记账；失败仍保留，不只选PASS。
4. 不因数值难看删除离群点。记录明确测量错误时保留原值及理由，图中或附表给出含/不含该记录的口径。
5. 身份正确输出占已开始帧、占完整帧及占计划槽是不同分母；正式论文先固定主指标，并报告覆盖率与错选率，避免只在输出帧上算准确率。
6. 端点净位移、采样航程、停止距离分别计算；首次实际清零与物理停止分别解释。
7. 分位数由对应事件集合计算，不相加不同组件P95；并行阶段用实际关键路径计时。
8. 统计以独立会话/测试回合为实验单位，帧和指令作为嵌套记录。现在两测试会话的检测结果仅描述；不能给56个实例套独立样本置信区间。

以上继承现有分母、时钟、失败与版本纪律。[检测分组](../research-plan-20261004/任务一专用YOLO首轮结果与后续闭环.md)、[运动重复](../research-plan-20261004/任务一运动尺度重复验证与论文更新.md)、[组件计时](../research-plan-20261004/任务一有界后台记录与尺度复验结果.md)。

## 4. 正式对照时采用的统计方案

正式方法共享场景种子、起点、检测输入、允许信息、资源与终止条件。为每个共同条件建立`pair_id`，预先安排或平衡方法顺序。[正式对照清单](../research-plan-20261004/任务一完整几何执行与正式对照接续清单.md)

后续方案建议：正文同时显示各独立回合的点、预声明汇总值和分母；共同场景采用配对差值。重复量充分时，可按独立会话/种子而非逐帧重采样计算95%区间，并保存算法、次数、随机种子及是否配对。回合数量、主指标、效应量和检验方法需在正式数据消费前冻结；本轮不做显著性检验、不凭当前小样本生成推断区间。

强化学习按训练种子分别保存原曲线，固定测试场景与评估频率。独立训练种子、每种子测试回合、环境交互步数分别报告；一份模型的多个测试回合不能增加独立训练次数。[T3研究与图表计划](../research-plan-20261004/硕士论文章节任务与图表安排.md)

## 5. 每类问题使用什么图

| 研究问题 | 首选图型 | 每点/线含义 | 当前可用性 |
|---|---|---|---|
| 原检测器与专用模型差异 | 配对点图 | 同一独立测试会话的两方法指标 | 已从2会话生成 |
| 延迟与执行时效关系 | 散点图、事件时间线 | 单个绑定源帧的派发/清零事件 | 已从369主帧生成 |
| 无输出、缺采与整帧成本 | 分母组成图 + ECDF | 计划槽状态；已知事件的完整分布 | 已从V11三会话生成 |
| 正式T1方法收益 | 独立回合点图、配对差值图 | 每点是会话，不是帧 | 待正式采集 |
| 轨迹、遮挡与恢复机制 | 等比例XY/3D轨迹 + 时间曲线 | 同一回合的实际状态、参考轨迹与失锁区间 | 需匹配正式回合 |
| YOLO/VLX及目标项贡献 | 消融点图、效果—成本散点 | 同条件完整方法与模块关闭后的回合 | 待正式采集 |
| T2互补与通信扰动 | 联合观测时间图、延迟—失锁散点、交接点图 | 共同回合、实际接收消息与交接事件 | 待开发与采集 |
| T3强化学习与规则比较 | 各训练种子曲线、测试点图 | 独立训练种子与固定测试回合 | 待训练与测试 |

箱线/小提琴图仅在独立回合数量足够呈现分布时使用，并叠加原始点；n=2不画小提琴或大样本误差带。二维轨迹坐标等比例；三维透视图配一张XY平面图，便于比较实际距离。这些是本项目后续出图约定。

## 6. 科研图统一样式

- 中文轴、图例和正文图注，YOLO/VLX/MAPPO、版本及SI单位可保留；画布不放大标题和长说明。
- 白底、黑色细轴框、向内主次刻度，默认无网格；黑/蓝两色配空心圆/方形及实线/虚线区分，门槛用灰色参考线。中文宋体、数值刻度Times New Roman。
- 点表示真实观测；遮挡用透明度解决，若水平抖动则只改变分类展示位置并明示，不改变测量值。
- 小样本展示全部独立点；时序曲线不得跨缺采槽补线。平滑曲线仅作辅助，保留原曲线并标注窗口。
- 每图附方法、条件、n及单位、分母、阈值、失败/缺失、是否仅开发验证。
- 当前独立图约95×75毫米，保存PNG 600 dpi、矢量PDF/SVG及可编辑Origin工程；最终插入学校模板后按实际栏宽复查字体、图例、留白和灰度可辨性。
- 交付CSV、输入快照、绘图脚本、软件版本、字体与文件SHA256；PNG和PDF渲染均目视检查。
