# UE4 鼠标观察视角优化验收（2026-10-14）

本轮完成同一 AirSim 会话中的原生观察相机。默认距无人机 18 米、俯视角 25°并跟随；左拖旋转、右拖平移、滚轮缩放、双击无人机聚焦。左上角提供聚焦、跟随开关和整体场景按钮。右拖关闭跟随；隐藏后重新显示保留观察参数。观察 Actor 只改变自己的位置、玩家观察目标和鼠标输入模式，不向无人机发送飞行指令。

## 实现与启动

- [观察相机](D:/forAirsim/external/AirSim/Unreal/Environments/Blocks/Source/Blocks/DroneControlObserver.cpp)位于本任务 Blocks 模块；仅新增 Slate/SlateCore 模块依赖。
- [编译脚本](D:/forAirsim/scripts/build_dual_target_observer.ps1)已在 UE4.27、MSVC 14.38.33130 下通过。它检查工程未运行及模块 BuildId 与引擎匹配。
- [安装脚本](D:/forAirsim/scripts/unreal/install_drone_control_observer.py)只向独立控制地图安装一个 `DC_MouseObserver`，校验任务地图标记并保留其他 Actor。[安装回执](D:/forAirsim/logs/dual_target_mouse_observer_install.json)为 PASS。启动器按地图哈希判断是否需要安装。
- [入口](D:/forAirsim/03_三维双目标控制.cmd)打开后不会自动起飞。点击“启动仿真”，连接后点击“查看 UE4 场景”。使用方式见[控制说明](D:/forAirsim/docs/三维双目标控制.md)。

## AirSim 飞行验证

最终运行：[dual_target_airsim_20261014_154512_469445](D:/forAirsim/logs/dual_target_airsim_20261014_154512_469445/validation.json)，90 秒任务飞行，3501 条记录，4 次命中，PASS。实际轨迹位于默认 100×100 米、高度 2～25 米范围。暂停保留目标队列，约 2.031 秒后速度降至 0.298 m/s。

飞行期间显示、隐藏、再显示 UE 窗口使用同一进程，控制继续运行，隐藏时目标队列保持。两次只读观察回执确认跟随中心等于实际无人机世界坐标，屏幕中心误差均小于 1 像素。最终主视口恢复不渲染，落地、解除武装及释放 API 控制全部成功，测试引擎进程已退出。[收尾回执](D:/forAirsim/logs/dual_target_airsim_20261014_154512_469445/cleanup.json)。

前一次同样 90 秒运行保留在[154213_876910](D:/forAirsim/logs/dual_target_airsim_20261014_154213_876910/validation.json)。该次 4 次命中、场景切换与落地均成功，但新增验收把玩家相机管理器上一渲染帧的缓存位置差限制为 1 厘米，产生 FAIL；实际屏幕中心误差约 0.67 像素。修正为检查屏幕居中误差小于 5 像素，并限制缓存位置差小于 50 厘米后重新运行，取得上述 PASS；未改写前一次失败结果。
