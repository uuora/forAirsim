# 已能运行03的另一台电脑：同步新增实验

复用已有UE4/AirSim和`.venv/python.exe`环境，无需重新搭建仿真。

1. 在项目根目录拉取正确分支（已有修改先保留，不要强制覆盖）：

```powershell
git fetch origin
git switch codex/hermite-disturbance
git pull --ff-only
```

2. 补齐实验资源，默认不启动仿真或飞行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/setup-control-reproduction.ps1
```

脚本只检查原环境、获取固定Git blob的ABOM网络、恢复必要冻结方案与本轮数据、重算36条记录。不会重装环境、安装UE、编译或改物理配置；已有不同内容不会覆盖。

原03不需要Torch，因此另一台仍可能缺少它。需要时在原环境补装：

```powershell
.venv/python.exe -m pip install torch==2.11.0 --index-url https://download.pytorch.org/whl/cpu
```

原实验用Torch2.11.0+cu128，搜索仅在CPU执行；不同backend和硬件不保证逐数值和时序相同。requirements-control.txt记录直接依赖版本，已有环境可用时不建议整套重装。

3. 双击`打开轨迹实验面板.cmd`，选择方法和任务，再点击开始。协议16连续规划在准备点设置区进入；日常GUI改进候选对应P，PGL等研究八臂用专用脚本。详见[完整流程与判据](完整控制实验_步骤与评判标准_20261101.md)。

4. 看历史结果：`reports/control_full_flow_20261101_v1/analysis/index.html`。本次归档包含36条AirSim记录（保留全部8次在线失败）、192次代理搜索、必要启动方案和开发请求来源，不包含全部历史批次。

若项目路径不同，旧HTML里部分file:///D:/forAirsim链接属于原电脑，可在新目录生成本地链接：

```powershell
$env:PYTHONPATH="$PWD/python"
.venv/python.exe python/analyze_control_full_flow.py reports/control_full_flow_20261101_v1 --output reports/recomputed_full_flow_local
```

输出目录须是新的。路径映射只用于读取，原始JSON/CSV、源码快照、条件指纹不改写；归档清单核验原字节哈希。

历史重算应得到固定路线12/12、在线16/24通过，36/36记录一致性审计通过。重新飞行受硬件、调度、墙钟预算、物理积分影响，不能承诺每次数字相同或在线全部通过。本次未在第二台电脑实际执行，应先跑普通曲线小规模核验。

本次上传不包含.env、Python/UE安装、编译DLL、下载论文或无关模型权重。AirSim本地C++和地图保存在patches/airsim-local.patch，已有03环境不要盲目重复应用；只有版本不匹配时按[补丁说明](../../patches/README.md)检查和重建。
