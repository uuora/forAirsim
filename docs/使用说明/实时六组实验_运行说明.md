# 原03框架：六种方法 × 两组多点控制实验

双击 `打开轨迹实验面板.cmd`。标题应包含“六种方法 × 两组多点实验”和“协议14”。也可从 `03_三维双目标控制.cmd` 原界面的六组实验按钮打开。保留原03的地图、启动器、原生观察器与真实起飞/降落流程；无障碍物。

## 怎样运行

1. 点击“启动仿真”，等连接完成。连接后先预览红色当前航点、蓝色下一航点及整条参考轨迹；不会自动起飞。
2. 用“编辑多点路线”设定1至10个有序航点；起点固定 `(0,0,5)` 米。默认路线为 `(8,0,5) → (12,6,7) → (6,10,6)`。坐标是 x、y、向上高度，单位米。
3. 选择实验组：“逐点停稳”或“连续过点”。选择六种方法之一，点击“开始飞行”，仅运行所选方法。切换方法、切换组、加载方案和生成方案均不自动飞行。
4. 修改航点、过点速度、停留时间、速度指令上限、变化率上限或时间倍率后，点击“生成当前组路线”。生成过程在简化模型中搜索六套冻结方案。相同参数的既有方案可复用。
5. 要跑六组方法，点击“勾选批量运行”→“全选六种方法”→选择一个实验组（6次），或勾选两个实验组（12次）→“启动所选实验”。也可只勾选任意两三种。批量入口不默认勾选六种方法。
6. 每条路线的中间点在同一次飞行中连续执行，末点完成后保存、降落，再执行下一项；复用同一UE实例。“本次后停止批量”取消后续项目；“停止并降落”同时停止本次。停止、失败和未运行记录全部保留。
7. UE内左拖旋转、右拖平移、滚轮缩放，双击无人机聚焦，左上角可切换跟随。红球代表当前航点，蓝球代表下一点；处理完的点移走，最后红球到达后隐藏。球是显示标记，不是障碍物或视觉控制输入。

## 两组各评什么

| 固定任务规则 | 逐点停稳 | 连续过点 |
|---|---|---|
| 共同有序航点 | 相同 | 相同 |
| 中间点参考速度 | 0 | 默认1.2米/秒，方向沿相邻段夹角平分线 |
| 中间点预定停留 | 默认1秒 | 无 |
| 中间点实际速度判据 | 停留结束时≤0.30米/秒 | 计划过点时刻≥0.50米/秒 |
| 中间点位置判据 | 核验时刻距航点≤0.50米 | 同左 |
| 最后一点 | 参考静止；终端位置≤0.25米、速度≤0.50米/秒 | 同左 |
| 全程采样同步峰值误差 | ≤0.50米 | 同左 |

两组是不同任务，分别比较六种方法，不把连续组更短的时间当作某个算法提效。连续组暂拒绝相邻点接近原地掉头的路线（转角余弦小于−0.85）；先保留清楚的适用边界。任一规则没通过就记录失败，不能放宽门槛改为成功。

固定底层控制律为速度前馈 + 位置误差反馈 + 速度误差反馈 + 加速度前馈，增益2、0.8、0.9；速度指令上限6米/秒、指令变化率上限6米/秒²、偏航指令角速度上限120度/秒，控制目标50Hz。上限不等于实测达到的速度。控制期间不暂停物理引擎；状态按AirSim时间戳与同一时刻的参考位置、速度对齐。

每段采用端点位置/速度/加速度约束的五次基线，叠加保持端状态的六次位移扰动。未优化参考扰动为0，实际次数不超过5；扰动族最高6次。每段4个搜索变量为dx、dy、dz、基础T，3个航点联合搜索12维。位移范围±(0.8,1.4,0.8)米，基础T范围3至7秒；实际段时长除以共同倍率1.25。Bézier/Hermite只改变构造表示，物理参数域相同；同一轨迹换基不是性能创新。

## 后续ABOM优先尝试什么

建议把“节省评价成本”与“改善控制轨迹”拆成两个可检验模块：先用便宜的动态界限与整条路线代理评价筛候选，再让少量不确定或有希望的候选进入AirSim；根据代理与AirSim的误差决定下一次昂贵评价投向。只有观测到有效改进时才增加网络更新，统计更新开销与最终可行质量。过点速度、减速位置可在固定任务规则内作为新增连续变量，单独消融，避免同时改控制器后无法解释收益。

这只是下一阶段设计，当前未实现AirSim参与搜索，也没有多保真提效证据。ABOM本身已有用当前种群在线更新参数化算子的机制（[原论文](https://arxiv.org/html/2601.21475v2)）；资源分配、多保真优化也已有研究（[BOHB原文](https://proceedings.mlr.press/v80/falkner18a.html)）。因此不能把“加入反馈”或“增加一层筛选”本身当作已确立创新。更具体的待检验贡献是：针对高速无人机轨迹的模型失配与控制约束，是否能在固定墙钟预算下减少AirSim评价、保持成功率与跟踪精度。需与同预算基础ABOM、轻量随机/坐标搜索，以及同容量但冻结更新的网络版本比较，并保留负结果。文献链接于2026-10-30核对。
