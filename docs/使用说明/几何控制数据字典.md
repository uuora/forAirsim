# 几何控制验证数据字典

适用于独立 `geometric_hybrid_v1`，不适用于旧协议13–16。原始记录不做平滑、插值或失败筛除；绘图抽样不进入指标。所有时间、误差、指令由实际状态记录重算，不从Qt图标推断姿态。

| 文件/字段 | 含义与单位 |
|---|---|
| config.json | 本次完整独立配置；调试阈值按次冻结，不为轨迹方法分别调整 |
| manifest.json | 任务、配置SHA256、源码快照SHA256、条件指纹、实际设置、版本、进程、动力初始化回执、实际加载DLL路径与SHA256 |
| manifest.planning_wall_s | 参考实例构造的主机墙钟秒；不含启动、预检、显示预览和准备飞行；本轮无搜索 |
| manifest.live.environment | 实际环境重力向量m/s²、空气密度kg/m³；仅记录，未进行推力标定或自动补偿 |
| samples.jsonl | 逐条原始状态与参考/指令，独立后台线程持续落盘；包括准备、几何悬停收敛、执行、降落及故障帧 |
| timestamp_ns | AirSim状态时间戳ns；同步参考时钟从RELEASE时间戳相减产生，不使用RPC收件主机时间代替 |
| host_read_begin_s / host_received_s | 主机单调时钟，状态RPC开始/返回；差值为客户端观测耗时 |
| host_before_send_s / host_send_return_s | 发令前/异步调用返回主机时刻；不代表电机已执行或物理响应延迟 |
| state_interval_s | 相邻状态时间戳差秒；故障帧先保存再中止，不能用正常样本掩盖大间隔 |
| phase | PREPARING、GEOMETRIC_SETTLING、TRACKING、LANDING；任务指标仅对TRACKING；准备和降落不计完成时间 |
| t | 自释放起的同步仿真秒；几何收敛阶段固定0；终点稳定保持纳入实际完成时间 |
| position / velocity / acceleration | AirSim kinematics_estimated原值：位置m、线速度m/s、线加速度m/s²；世界NED，Z向下。SimpleFlight目前是理想状态反馈 |
| quaternion_wxyz | 机体FRD到世界NED的实际旋转，按w,x,y,z存储；不是欧拉角 |
| angular_velocity | 机体FRD角速度rad/s；范数用于安全检查 |
| collision / collision_timestamp_ns | AirSim碰撞标记及事件时间；可能保留历史接触。只判定起飞后基线之后的新碰撞，不能只看布尔值 |
| reference.p/v/a/jerk/snap | 解析时参参考，单位依次为m、m/s、m/s²、m/s³、m/s⁴，世界NED；jerk连续，分段snap不保证连续 |
| reference.yaw / yaw_rate | 参考航向rad、rad/s；当前各任务为恒定航向，未验证动态航向跟踪 |
| R_reference | 仅由参考加速度和航向生成的期望旋转；行列为3×3，机体到世界 |
| command.R_des | 加入位置/速度反馈和限幅后的实际姿态目标；与R_reference分开 |
| attitude_reference_error_rad | angle(R_referenceᵀ R_actual)，SO(3)主旋转角，不相减欧拉角 |
| command.attitude_error_rad | angle(command.R_desᵀ R_actual)，对实际姿态目标的跟踪误差 |
| command.roll/pitch/yaw | 物理NED/FRD ZYX姿态目标rad；传Python接口时显式使用roll,-pitch,-yaw抵消wrapper翻转 |
| command.throttle | 0–1归一化总油门指令；名义推力映射为线性，含内环混控和空气密度影响，不能称实测牛顿推力 |
| command.saturation | 加速度、竖直力、倾角、合力、油门、非正投影、航向退化各标记；不是电机饱和的完整观测 |
| command_sent / failure | 本帧是否发令、故障原因；未发令不能解释为零指令或任务成功 |
| metrics_samples.csv | 从JSONL独立重算的逐样本误差、速度、姿态、安全量、油门和饱和；存在时重审会核对，不覆盖不同内容 |
| events.json | RELEASE、TERMINAL_STABLE、失败、显示异常和碰撞基线等事件 |
| cleanup.json | 地面接触持续核验、解除解锁、landed状态及控制权释放；清理失败不伪记为已落地 |
| audit.json | 独立四元数/旋转/参考多项式/时间/起终点保持/CSV/来源检查；审计通过不代表控制通过 |
| report.json | 正常完成、控制门槛、数据审计、清理分别报告；accepted要求这些条件共同成立 |

RMSE采用从释放到完成的右端采样保持时间加权；峰值取原始样本，超限时长按同一保持约定积分。首个释放到执行样本的间隔也计入检查。终点必须在完整参考结束之后满足位置、实际速度、参考姿态并持续1秒。任务时间不是单纯参考时长。

控制门槛当前以同步位置误差与同步参考姿态误差为主；实际姿态指令误差另列同一10°诊断界。本轮2倍速两者均超界。速度误差、油门、指令饱和与实际安全量分别保留，不将未观测电机饱和写成零。

重审命令：`.\.venv\python.exe python/run_geometric_control_validation.py --audit <新协议目录>`。此命令无AirSim调用，仅生成/核验派生CSV和审计文件；原始JSONL不重写。
