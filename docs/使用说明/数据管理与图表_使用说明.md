# Qt5实验工作台：数据管理与图表使用

双击 `打开轨迹实验面板.cmd`，仍使用原03地图和协议14控制流程；默认不连接、不起飞。只整理数据可双击 `历史工具/管理仿真实验数据.cmd`，直接进入数据页。

## 三个页面

- **实验控制**：左侧选择停稳/连续组、方法、航点与参数，中间观察三维场地和实时状态。启动/连接在右上，开始、暂停、停止降落与批量入口固定在底部。常用控制不随侧栏滚动。
- **数据管理**：按类别、实验组、协议、结果筛选；搜索框也支持方法名称、目录、种子、标签和备注。勾选记录后生成对比；不同条件分开展示。
- **图表对比**：在面板内切换条件组和图种，选择适合窗口/宽度/原始尺寸，或用加减号缩放。可导出PNG、SVG、PDF，完整数据页仍保留。关闭当前结果后，其旧图目录才可进入归档。

## 日常数据整理

1. 点击“刷新索引”扫描 `logs` 和 `reports`，只读原始目录。新完成的飞行、批量与方案会自动归类。现有索引位于 `experiment_data/catalog.sqlite3`，同时导出 `catalog.json`、`catalog.csv` 和 `index.html`。
2. 点击记录查看完整路径、协议、方法、种子、条件指纹、错误和大小。双击飞行记录查看单条曲线；勾选两条以上后点击“生成所选对比”。
3. 右侧可填标签、备注并勾选“固定保留”。这些信息单独保存，重新扫描不会丢失，也不写回原始日志。
4. 曲线飞行、原03控制日志、其他原始日志、批量、冻结规划方案、派生图表和研究资料分别分类。未知格式保留；无效、失败和不完整记录不会被当作0误差或自动隐藏。索引中的“控制通过”来自保存的判据，独立审计在生成图表时进行。

## 可恢复清理

1. 筛选“派生图表”，勾选旧目录，点击“预览归档旧图表”。先看具体目录、文件数和大小，再按“执行可恢复归档”。
2. 系统先压缩并逐文件SHA-256校验；再次检查内容未变化后才清理原派生目录。压缩包和恢复清单保存在 `experiment_data/archive/`。压缩主要减少目录杂乱，不保证显著节省磁盘空间。
3. 筛选结果“已归档”，选择一项并点击“恢复所选归档”。恢复到原位置；存在不同内容时拒绝覆盖。
4. 原始飞行、失败日志、冻结方案、未知文件、正在使用的目录及“固定保留”项受保护。当前默认结果页也受保护。若旧图正在图表页中查看，先点“关闭当前结果”。
5. 预览后文件变化需重新预览；中断后保留归档状态和清单。数据任务期间禁止启动飞行；归档/恢复未完成时关闭窗口会等任务结束。

本轮实际归档了 `live_curve_protocol13_comparison_v1` 与 `v2` 两版旧图页，最新版v3、全部原始记录均保留；24个关联原始文件的哈希未变化。操作回执在 `experiment_data/cleanup_result.json`。历史说明中的旧版图页路径需要先在数据管理中恢复，才能打开。

## 新图表怎样读

六种方法固定颜色，切换选择或顺序不会换色。输出包含三维轨迹、XY/XZ等物理比例投影、同步误差及0.50米门槛、逐条记录的参考/实际/指令速度与朝向、执行质量与模型规划耗时。超过六条的逐条曲线会分页，不静默遗漏。

误差图使用原始时间与采样，不平滑、不按归一化进度冒充同步时间。指标图显示每次记录的原始点，多次记录加中位数；不把单次数据画成置信区间。缺失值标为无有效值；完成、控制通过与任务成功分别保留。

每个独立条件组都有高清PNG、SVG/PDF矢量图、`plot_data.npz`、配色与图清单、中文/程序CSV、独立审计以及 `plot_source/` 绘图源码快照。根目录 `历史工具/查看六组仿真对比.cmd` 打开已重绘的12次开发验证结果。新生成的对比在 `reports/control_view_时间戳/`，可在记录库中再次找到。

本次只用已有真实AirSim日志重绘与核验界面，没有增加飞行数据。控制器、物理设置、判据和冻结曲线解码源码与最终协议14冒烟快照一致。界面预览在 `reports/qt_workspace_v2/`，属于Qt离屏界面核验，不是AirSim相机截图。回归测试与界面端到端回执也在该目录；符号链接创建测试受Windows权限限制时会明确跳过。
