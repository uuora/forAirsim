## 3. 坐标、旋转、接口及推力

AirSim本地源码文档`external/AirSim/docs/apis.md:237,251`规定：位置、线速度和线加速度是世界NED、SI单位；角速度和角加速度是机体系。SimpleFlight的`estimated`状态目前直接取理想真实运动学（`AirSimSimpleFlightEstimator.hpp:23`），本验证不包含真实传感器估计误差。

新数值层统一用世界NED与机体FRD，`R`将机体向量变到世界；原始AirSim四元数字段明确重排记录为`[w,x,y,z]`。`VectorMath.hpp:261`的旋转及`:305`的ZYX Euler转换支持此约定。物理推力沿`-R e3`（`MultiRotorParams.hpp:117`）；平动方程采用`a=F_world/m+g_world`（`physics/FastPhysicsEngine.hpp:367`）。不把Qt的翻转高度操作当成旋转矩阵变换。

可用接口如下：

| Python接口 | 单位与通道 | 实际内部职责 |
|---|---|---|
| `moveByRollPitchYawThrottleAsync` | SimpleFlight角度为rad，throttle为0–1 | 自有期望姿态，SF角度／角速度环与混控 |
| `moveByAngleRatesThrottleAsync` | rad/s，throttle为0–1 | 可自有姿态到角速度律；SF角速度环和混控仍在 |
| `moveByMotorPWMsAsync` | 前右、后左、前左、后右；各0–1 | 全轴Passthrough，绕过混控；需自有力矩和电机分配并另行验证 |

关键符号不能仅凭Python文档里的FLU文字推断：`PythonClient/airsim/client.py:1354`实际把`(roll,pitch,yaw)`变成RPC的`(roll,-pitch,-yaw)`；`SimpleFlightApi.hpp:226`直接把RPC角度与原生NED四元数转得的Euler角比较。因此，对数值层给出的NED目标`(φ,θ,ψ)`，Python调用必须传`(φ,-θ,-ψ)`。角速度wrapper也翻转pitch/yaw rate。实飞前用接口替身检查这条映射，并做正方向、小角度与悬停验证。

`RotorActuator.hpp:60,119–133`显示，归一化控制输入先限到0–1并经过时间常数0.005s的滤波；名义推力为`u_filtered * F_max`，不是再次计算`u²`。实际力还乘`ρ/ρ0`，其中`ρ0=EarthUtils::getAirDensity(0)`。故`1/TWR≈0.4`只是当前名义水平悬停映射，密度及当地重力会造成偏差：

`u_hover ≈ m*g_live / (ΣF_max * ρ_live/ρ0)`。

`simGetGroundTruthEnvironment`提供重力和密度。当前实现不应把名义0.4称为校准结果；悬停误差与偏置要实际报告。混控器会整体抬升、缩放和逐电机裁剪（`Mixer.hpp:31–47`），油门处于范围内不证明电机无饱和。日志区分外层指令限幅、实测姿态/角速度安全界和未直接观测的内部电机饱和。

服务端持续命令的刷新周期为50Hz（`SimpleFlightApi.hpp:183`）；最后刷新停止后，SF在额外60ms超时后进入内部位置悬停（`firmware/OffboardApi.hpp:46`）。这是退化保护，不是瞬间刹停或硬实时保证。控制循环不逐次等待整个命令持续时间结束。

准备阶段也核验状态间隔、实际倾角/角速度/速度与阶段边界；爬升阶段边界明确包含地面。实际离地后记录新的碰撞基准时间戳，保留之前预期地面接触；执行期新碰撞按时间戳判断，不把AirSim持续保留的旧碰撞布尔值直接判成新碰撞。日志或显示异常可使任务失败，但不再直接阻断降落控制；收尾证据不足时保留失败和控制权状态，不伪称安全完成。

## 4. 公式来源与适配

采用Lee、Leok、McClamroch的[CDC 2010作者版论文](https://mleok.science/pdf/LeLeMc2010_quadrotor.pdf)，限定第5422页式(12)、(15)及其航向构造。其他arXiv版本的公式编号不同，不能替换链接后继续照抄编号。

令`e_p=p-p_ref`、`e_v=v-v_ref`，使用质量归一化增益：

```text
a_c = a_ref - Kp*e_p - Kv*e_v
h   = g*e3 - a_c
b3d = h / ||h||
b1h = [cos(yaw_ref), sin(yaw_ref), 0]
b2d = normalize(b3d × b1h)
Rd  = [b2d × b3d, b2d, b3d]
f/m = h · (R*e3)
```

代码另外明确实施加速度幅值、竖直分量下限、倾角锥、合推力及油门限幅；非正投影和航向退化单列标记。退化时确定性选取非平行轴，避免除零，但该退化方向不保证维持原航向。上述限幅、离散采样、SimpleFlight PID和电机滞后不属于论文原定理，不能宣称相同收敛性质。

**式(16)的几何力矩律没有实现。** `Rd`转Euler后发送给SimpleFlight。保留`R_reference`（仅参考加速度/偏航生成）与`command.R_des`（含位置/速度反馈与限幅），分别计算相对同步参考的姿态误差和对实际指令的姿态跟踪误差；不能混为同一指标。

姿态评价采用主旋转误差角`θ=angle(R_refᵀ R_actual)`，范围0到π，数值实现采用等价`atan2(sinθ,cosθ)`表达，避免零点及π附近单纯`acos`的数值问题。不直接相减Euler角。实际倾角`acos(e3ᵀ R e3)`与机体系角速度范数是独立安全指标。

## 5. 调试门槛与冻结原则

`configs/geometric_control_validation.json`是独立配置。下表是**首轮调试建议**，每次运行前连同源码与配置冻结；它们不是已通过验证的研究验收标准，也不是从旧实验结论继承的物理保证。

| 项目 | 当前建议 | 依据与边界 |
|---|---|---|
| 指令倾角/油门 | 25°，0.08–0.8 | 直立小范围调试，保留姿态控制和上推力余量；不代表全部高速任务可行域 |
| 实际倾角/角速度 | 35°，3rad/s | 超过指令域的独立中止保护；需要后续实测确认余量 |
| 实际速度/安全盒 | 6m/s；X/Y±20m，高度1–15m | 首轮局部任务的范围保护，不声称场地外同样安全 |
| 同步误差 | 位置0.5m；SO(3)参考姿态10° | 初期可解释的调试界，报告峰值与超限时长，不凭单一RMSE掩盖短时违约 |
| 发散保护 | 位置误差1.5m | 与评价界分开，中止不等于通过 |
| 起点 | 位置0.1m、速度0.1m/s、姿态3°，持续1s | 减少释放初态差异；起点收敛、真实起飞时间不计任务完成时间 |
| 终点 | 位置0.15m、速度0.15m/s、姿态5°，持续1s | 将短时穿过目标与稳定到达区分 |
| 采样间隔 | 最大0.1s；目标50Hz | 允许观测少量异步时差但拒绝大断档；不因失败放宽 |

先检查坐标、悬停平衡、正方向、SO(3)误差和限幅，再逐级悬停→直线→平滑转弯→多航点。只有前级正常完成、控制门槛和独立审计分别通过，才晋级；高速测试另行预声明任务和速度阶梯。基线验证后应依据任务容差、物理余量与测量重复性冻结共同验收界，不能针对Bézier/Hermite/B样条分别调界。
