# 推重比与穿越机迁移

背景确认：老师要求后续面向穿越机，推重比大于 2；截至 2026-10-15 尚无实机型号和动力参数。本任务现采用 1 kg、标称推重比 2.5 的试验动力配置，并保留原型速度配置；这是仿真设定，后续应以实机参数替换。

## 含义

推重比 r = 最大总推力 / (整机质量 × g)，整机质量包括电池、相机与其他负载。以起飞质量 1 kg 为例，r=2 对应最大总推力约 19.6 N，约 2 kgf。比值更大意味着有更大的推力余量，可用于加速和爬升；该比值应对应整机及明确测量条件。[NASA 定义与性能说明](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/thrust-to-weight-ratio/)

理想竖直全推力、忽略阻力时，由牛顿定律可得净加速度上界 a=(r−1)g。因此 r=2 时约 9.8 m/s²。这个推导不是建议的规划加速度，实际需要给姿态控制留余量，并考虑电机响应、电池电压、阻力和飞控限幅。维持高度的倾斜飞行还需满足 T cosθ=mg；横向加速与倾角和推力共同相关，不能直接把竖直上界当成水平加速度。

r=2 时悬停需要约一半最大总推力，并不意味着油门必为 50%。电机/电调推力曲线通常非线性，需根据实际动力组合测量。[ArduPilot 推力曲线说明](https://ardupilot.org/copter/docs/motor-thrust-scaling.html)

## 当前实现与差异

本地 SimpleFlight 选择 Generic QuadX：4 旋翼、机臂 0.2275 m。未选择动力配置时，原模型仍为质量 1.0 kg、单旋翼最大推力约 4.179446 N、标称推重比约 1.70474。2026-10-15 新增了本任务使用的 `DynamicsProfile` 扩展，当前设置如下：

```json
"DynamicsProfile": {
  "Schema": 1,
  "Name": "dual_target_v1",
  "MassKg": 1.0,
  "ThrustToWeightRatio": 2.5
}
```

该字段位于 `configs/dual_target_airsim_settings.json` 的 `Vehicles/DroneControl` 中，需要本工作区已编译的新 AirSim 插件支持。启动时通过改变最大转速并重算推力、扭矩来匹配所请求的推重比；机体惯量也按质量重算。当前单旋翼最大推力约 6.129157 N、总最大推力约 24.516626 N，初始化回执标称推重比约 2.5000001。[实际启动与飞行记录](../logs/dual_target_airsim_20261015_195157_981361/dynamics.json)。这是加载模型的初始化参数核验，尚不是实际推力标定。

配置只对显式选择该扩展的机型生效。质量须大于固定四个电机组件的合计质量 0.22 kg，推重比支持 `(1,3]`；这是当前扩展与 SimpleFlight 速度控制限幅共同适用的范围，不能作为所有无人机的动力范围。当前归一化悬停推力约 0.4，高于速度控制器约 0.3 的最小值，起飞、暂停、下降与落地已实测验证。原源码中“怠速为 50%”的注释与当前固件参数不一致，不应据此推断推重比超过 2 必然无法降落。

修改模型代码后执行 `scripts/build_dual_target_dynamics.ps1`，修改动力设置后重新启动仿真。连接时核验运行中的 settings、UE 进程及 `DTC_DYNAMICS` 启动回执，旧插件静默忽略新字段时拒绝起飞。当前没有通过 Python API 在空中修改质量或推力的功能。

规划当前限制为 4 m/s、4 m/s²、偏航指令变化率 120°/s。它们限制的是规划与控制指令，不证明实测响应已达到这些指标。后续获得实机质量、推力、惯量、电机延迟、阻力及姿态限制后，应继续校准模型；不能仅提高 max_speed 就称为穿越机仿真。

双目标联合规划和提前转弯框架可以保留。高速版本需进一步加入推力、倾角、角速度以及延迟约束，按实际制动能力计算边界。直线恒减速度的简化制动距离为 v²/(2a)，延迟 τ 另增加约 vτ 的行程；目前固定 1 m 缓冲不能直接沿用为高速实验的充分保证。推力饱和会影响高度、姿态及偏航控制，因此规划必须保留动力余量。[ArduPilot 推力饱和说明](https://ardupilot.org/copter/docs/thrust_loss_yaw_imbalance.html)

当前相机通过 simSetCameraPose 补偿机身姿态并主动朝向目标，相当于仿真云台。若实机是固定 FPV 相机，需要锁定安装角，将机身滚转、俯仰、偏航共同纳入三维视线约束；当前“位置命中＋水平偏航误差”不能证明固定相机光轴正对目标。

当前发送世界坐标速度和绝对偏航，由 SimpleFlight 执行底层姿态控制。实机能否接收同类指令取决于飞控与自主控制接口。若使用 Betaflight 的 Rate/Acro 模式，其操纵量以旋转速率为主，不能直接等同于当前速度控制接口；穿越机名称本身不决定飞控类型。[Betaflight 模式说明](https://betaflight.com/docs/wiki/guides/current/Modes)

## 后续参数与评估

获得硬件后至少记录：含电池/负载质量、最大总推力及测量条件、机架/惯量近似、电机响应、允许倾角与角速度、相机安装角、飞控型号与控制接口。

按速度档实测位置误差、进入到达半径所需时间、连续命中率、三维视线误差、规划耗时 P95/最大值、实际状态间隔、指令到响应延迟、边界余量及动力饱和。推重比是动力条件，规划计算速度与跟踪收敛速度应分别测量。
