## 检索前确定的边界

- 纳入：海上 UAV 搜救感知、船载感知数据集；相机内参/外参/时空标定、立体匹配、视觉惯性位姿；检测跟踪与评价；状态报告信息年龄；语言到机器人技能与轻量无人机指令系统。
- 纳入版本：能够在 Crossref + Semantic Scholar 或 arXiv 原站确认题名作者的论文；允许经典方法论文；正文未读的条目明确标记仅书目/摘要。
- 排除：与这些任务无关的检索结果、无法核验的条目、同一工作的重复版本、软件 README 充当论文、直接把实机/其他数据集的成绩当成当前项目成绩。
- 日期：基础方法不限制起始年；截至 2026-09-15 可核验的记录。LMUCS 的未来期次单独披露，不将其判成已读已发表全文。
- 语言：英语题名/元数据为主，中文阅读指南；本轮未检索 CNKI/万方/中文学位论文。

## 第一轮实际路径（17 条历史审计，不是最终计数）

1. 从主题匹配的基础论文与用户提供的 LMUCS 仓库建立种子题名。
2. Crossref `query.title` 每题返回最多 3 条。完整查询串、请求时间、HTTP 状态、快照哈希见 `search_log.json`、`retry_log.json`、`lmucs_retry.json`。这是题名定向查找，不是全库布尔穷尽检索；不将 API `total-results` 当成人工筛选数。
3. 人工检查返回的题名。ReAct 与 SayCan 的 Crossref 结果均不匹配，未采用其首条 DOI，改用 arXiv 原站确认。海事通信宽题查询保留首条确实相关的海上搜救 LTE 论文，不将返回的其他论文自动纳入。
4. 对 15 条含 DOI 记录逐条查询 Semantic Scholar，全部获得对应题名；程序断言规范化题名相似度 > 0.90。作者列表与年份保留两个来源原始响应便于核查。2 条 arXiv 记录的 S2 请求不可用，以原站元数据作为存在证据；不记作 S2 匹配。
5. DOI 解析尝试单独记录在 `doi_resolution_log.json` 与 `supplement_log.json`；网络失败/出版商访问限制不是论文不存在。元数据匹配状态不冒称所有出版商全文都已访问。
6. 阅读可获得摘要，形成阅读任务与适用边界；没有做全文方法评价。17 篇去重条目中，13 篇摘要、4 篇仅书目；LMUCS 另读仓库 README。未形成正文页码引用或人工已读声明。

## 纠错与版本

- 种子链接 `arXiv:1409.1073` 返回的是进化算法论文，与 Kalibr 时空标定题名不符；`arXiv:2105.01915` 返回恒星活动论文，与 SeaDronesSee 不符。均从证据中排除，原始快照保留用于审计，见 `verified_metadata.json.rejected_candidate_links`。SeaDronesSee 的正确 arXiv ID `2105.01922` 由 S2 元数据确认，同时已访问 CVF 正式页面。
- ReAct、SayCan 使用本轮实际核验的 2022 年 arXiv 版本；未用记忆补填会议出版元数据。
- AirSim 采用 2018 论文集版本，在线与预印本为 2017；HOTA 采用 2021 期刊卷期版本，在线为 2020。避免把在线年与卷期年混配。
- LMUCS 主条目 DOI `10.1016/j.ast.2026.112949`，期次为 2026-10；Crossref DOI 登记为 2026-06-22，检索日 DOI 能解析。精确在线发表日未确认。SSRN `10.2139/ssrn.5397714` 题名与作者顺序存在版本差异，没有另算一篇或混合字段。

## 质量与覆盖限制

这是语言模型/检索增强及计算机视觉/机器人/通信文献，不能机械套用医学 RCT 等级。所有条目记录 `method_quality=NOT_ASSESSED_FULL_TEXT`；期刊/会议元数据存在不代表其方法有效性或跨场景适用性经过本轮检验。没有查询付费的 Scopus/WoS/Cabell's，也没有完成作者资历、COI 和撤稿核查；不得把“未见异常”写成“确认无问题”。Crossref 的 update 字段按原值保留，字段为空不是无撤稿证明。OpenAlex 未调用，不能声称四索引交叉验证。

分布：最终 18 篇包含 2020–2024 年的 RAG、Self-RAG、Adaptive-RAG、LoRA、Qwen2.5 等语言主线基础，以及 2026 年的 LMUCS 与 LatentRAG；另保留较早的传感器、信息时效和感知评价文献作为支撑或扩展。仍未完成近三年观测证据冲突、过期识别与海事知识问答的专项检索，不能支撑“当前最优”或“首次提出”主张。预印本版本按预印本记录，无出版层级提升。地域信息不足，未作地域覆盖结论。已知方法类别主要为计算方法、基准与工具论文，是任务选取导致的集中；未开展全面方法设计编码，不能给出虚构比例。

下一批重点围绕语言/RAG 主线补充：近三年的 conflicting evidence / temporal reasoning / stale evidence detection / adaptive retrieval 文献，以及海事搜救知识问答、证据引用与信息不足时澄清的评价工作；同时收集具有清晰版本、发布日期和使用权限的海事权威知识来源，用于知识库与人工审核任务标签。比较重点是时效/冲突信号相对复杂度路由是否提供额外价值。相机同步、多机几何、海面立体匹配仅在用户启用定位扩展时补检，不作为语言主线启动前提。以上是后续检索计划，不是本轮已执行结果。
