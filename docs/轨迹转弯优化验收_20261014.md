# 轨迹转弯优化验收（2026-10-14）

当前版本已改善临近目标时擦过、急转、回追的问题。在默认请求速度上限 4 m/s、seed=13 的一次 90 秒 AirSim 验证中，四个目标均在首次球面入口合格命中，未出现近点距离反增后回追。全包 93 项测试通过，离线 24 组滞后场景的 48 个目标腿全部首次通过。[真实日志独立核对](../reports/dual_target_control/turn_fix_20261014/airsim_validation.json)、[离线矩阵](../reports/dual_target_control/turn_fix_20261014/offline_validation.json)、[测试输出](../reports/dual_target_control/turn_fix_20261014/unittest_full.log)。

## 原因与改动

原控制器使用两点入航/出航方向的等权角平分线，接近折返时会在目标附近要求较大的横移或升降；单纯追逐前视点，也容易在实际速度响应滞后时切弯。实际记录还发现，进入最后 3 米时横向位置误差只有约 0.045 米，横向速度仍约 1.045 m/s，之后偏差扩大到约 0.39 米，球入口朝向误差约 24.34°，超过 20° 门限，因而发生回追。[中间修订日志](../logs/dual_target_airsim_20261014_204629_965999/telemetry.jsonl)、[独立分析](../reports/dual_target_control/turn_fix_20261014/airsim_validation.json)。

改动集中在 [core.py](../python/dual_target_control/core.py) 与 [控制配置](../configs/dual_target_control.json)：

- 两点仍联合规划，通过方向改为偏向入航方向，下一点继续影响当前点前的轨迹及通过速度。
- 转弯提前完成，末端直线长度按速度与响应时间预留收敛距离；默认长航段为 5 米，短航段及边界附近按可行长度裁剪。固定 161 个路径采样点，解析规划。
- 跟踪改为切向速度前馈、横向位置纠偏及横向速度阻尼，前视距离随实测速度调整。
- 制动预算采用实测速度、跟踪偏差及预计横向漂移；配置 `response_time_s=0.35`。这是一项保守响应预算，尚非完整动力学辨识结果。
- 纠偏与前进速度共同受进点速度包络约束，给实际机头转向留时间；命中后速度命令仍受原加速度限制连续变化。
- 跨帧命中使用精确球面根，并在入口插值实际偏航；位置要求仍为 0.5 米、朝向要求仍为 20°。未合格通过的目标保留，并能重新面向目标恢复。

## 回归范围与使用

离线矩阵覆盖直角、接近折返、近边界、先升后降、先降后升和历史长距离进点；每种分别采用两档偏航滞后、固定与抖动时间间隔，共 24 组、48 个原始目标腿。旧版通过 8/24 组，首入口命中 30/48；最终版本通过 24/24 组，48/48 首入口命中、近点回头 0、未命中越过目标平面 0。[矩阵原始结果](../reports/dual_target_control/turn_fix_20261014/offline_validation.json)。

新增测试还覆盖非径向球面入口、实际偏航门限、球内错误朝向的恢复、纠偏限速，以及相同总速度下横向惯性提前制动。[转弯回归](../python/dual_target_control/test_turning.py)。离线模型是带位置积分及速度/偏航滞后的点质量模型，不能替代 AirSim 六自由度或实机验证。

中间两次真实验证仍存在第二点回追，记录均保留：[203906](../logs/dual_target_airsim_20261014_203906_863508/summary.json)、[204629](../logs/dual_target_airsim_20261014_204629_965999/summary.json)。最终追加末端收敛距离与横向漂移预算后，该点首次入口合格命中。源码和日志 SHA 审计信息保存在分析 JSON 中，历史日志没有改写。
