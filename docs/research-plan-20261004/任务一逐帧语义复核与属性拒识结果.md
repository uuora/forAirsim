# 任务一逐帧语义复核与属性拒识结果

日期：2026-10-05。当前仍为AirSim单机单目标任务：DroneA观测指定白条红气球，普通红气球作为干扰；DroneB未参与研究运动。本轮保留YOLO和VLX，未开展任务二、任务三或现实迁移。

## 1. 本轮实现

新增版本保存语义源帧至当前帧的完整YOLO候选序列。语义框须在源帧唯一匹配候选；随后每一跳须满足IoU阈值、竞争候选排除、帧序号连续、上下文和尺寸一致、真实读回间隔不超过0.5秒。遮挡、歧义或断帧会使该请求失效，不能在目标重新出现时接回旧链。回复完成时间与轮询时间分开判定，源图像时钟保持原值。[逐帧证明与复算](D:/forAirsim/python/t1_delayed_semantic_bridge.py)

新开发配置允许原始源年龄不超过8秒，传输设置为10秒；这些值不改变当前RGB的0.5秒、自状态的0.12秒和动作租约的0.12秒限制。接受语义结果后还须取得两帧实际更新图像，且仍不得越过原始源加8秒的期限。因此接近8秒才返回的回复可能来不及确认。10秒是连接/读取超时设置，不是整个请求的绝对时长保证。[配置与表面检查](D:/forAirsim/python/t1_candidate_surface_v3.py)、[动作限制](D:/forAirsim/python/t1_identity_motion_policy.py)

起飞稳定后增加最多20秒的初始身份获取阶段，期望XY速度保持零；确认当前身份和配对深度表面后才进入原定主测量窗口。获取帧、未使用的获取槽、主测量槽和失败分别保留，不把初始化称为遮挡恢复。[阶段与分母](D:/forAirsim/python/t1_identity_flight_v3.py)

## 3. 发现并处理的身份失败

短飞行V3原始运行器按“存在表面和非零动作”判PASS，独立资格仍为失败。错误的六帧均继承遮挡期间源帧f024的语义锚：指定气球不可见，VLX返回了普通红气球框；几何链随后持续保持这个错误来源。四次非零请求因此指向错误目标。源图像、请求、回复和链节点账本一致，这一失败来自错误语义选择，不能通过修正时间戳或删去试次解决。[错误帧与原始状态](D:/forAirsim/logs/t1_chain_analysis_final_v4p1_20261005/report.json)、[实际源图像](D:/forAirsim/logs/t1_identity_chain_short_v3_20261005/flight/frames/t1_identity_chain_short_v3_20261005_f024_rgb.png)

V4在采用语义回复前加入描述专用RGB检查：源图像哈希、请求绑定和源框唯一YOLO匹配必须成立，并在候选内部观察到宽白色横带及其上下的红色区域。未通过时保留真实VLX返回和检查记录，拒绝建立语义锚。该检查没有读取场景阶段、目标位置或分割标签。[源RGB检查](D:/forAirsim/python/t1_source_attribute_guard.py)

开发回放覆盖10个唯一语义来源：9个正确目标来源通过，1个错误干扰来源被拒绝。V4随后独立起飞，六次请求中五次通过属性检查、一次被拒绝，保存帧未发现错误身份或错误目标非零动作。回放是在失败诊断后进行，不能视为独立泛化测试，也不能用它重写V3飞行轨迹。[开发回放](D:/forAirsim/logs/t1_source_attribute_replay_v1_20261005/report.json)、[V4实际结果](D:/forAirsim/logs/t1_chain_analysis_final_v4p1_20261005/report.json)

## 4. 控制与处理时序

V4的15次非零请求均保存显式零速度清除，最小观测截止余量167毫秒；清除相对声明租约结束的最大晚到约21毫秒。整个获取与主测量期间专用状态查询最大间隔约78毫秒。两处停顿实际各0.657秒，分别有14、13个自状态回执，触及停顿的最大查询间隔均约63毫秒。[清除与查询审计](D:/forAirsim/logs/t1_chain_analysis_final_v4p1_20261005/report.json)

两处停顿没有活动的非零目标租约，当前仍缺少“非零动作执行期间主线程阻塞”的直接证据。V4实际门控37个及时、2个晚到、2个漏采未知；完整帧完成20个及时、19个晚到、2个未知。完整处理还含媒体保存和停稳，不能与动作门控时钟混用，更不能据此声称完整0.4秒闭环稳定或硬实时。[分事件时钟与全部时隙](D:/forAirsim/logs/t1_chain_analysis_final_v4p1_20261005/report.json)

V4主测量采样XY航程仅0.00753米，最大实际XY速度约0.00121 m/s。它证明有限条件下的感知至动作接口连接，尚不能用于评价有研究意义尺度上的轨迹优化效果。返回段有7个连续正确输出，读回跨度2.422秒；遮挡前已存在复核确认造成的输出中断，恢复延迟记为不适用。[阶段分开复算](D:/forAirsim/logs/t1_chain_analysis_final_v4p1_20261005/report.json)

三次飞行共16个语义请求，记录到的后端完成耗时均小于2秒，最大1.188秒。本轮没有真实超过2秒回复被桥接的飞行证据；该分支目前由受控Future测试覆盖。不得把8秒配置写成已实测的延迟容忍收益。[真实传输时钟](D:/forAirsim/logs/t1_chain_analysis_final_v4p1_20261005/report.json)、[完成与迟轮询测试](D:/forAirsim/python/test_t1_delayed_semantic_bridge.py)

## 5. 限制与接下来工作

当前RGB检查只针对本场景的红色气球和宽白横带。较大的白色圆形高光仍可能满足颜色模板，光照、远距离、视角和其他外观目标需要独立验证。它不能保证实例身份，也不是校准概率。飞行使用起飞前封存源码；随后补了越界语义框和截断候选的检查，两个边界以测试验证，未改写飞行记录。[属性范围与防御检查](D:/forAirsim/python/t1_source_attribute_guard.py)、[当前测试](D:/forAirsim/python/test_t1_source_attribute_guard.py)

下一步按以下顺序继续任务一：

1. 持续跟踪保持原有效锚，复核在后台取得两帧确认后再交接，减少复核引起的输出中断；冲突或过期继续拒绝。
2. 预声明在实际非零请求期间注入停顿，核验到期清除，并补慢语义回复与属性误判工况。
3. 在新冻结的执行预算下测量有意义的运动尺度、观测质量和执行响应，确认四方法使用共同起点、候选与约束。
4. 再开展正式四方法、YOLO后端和VLX消融及独立重复，分析错误率、有效观测、恢复、航程和处理成本。
