# 任务一严格停稳与异步完成验证方案

日期：2026-10-06。范围：单机、指定白色横条红气球、相似红气球干扰，AirSim受控开发验证。正式算法效能对照尚未开始。

## 1. 本轮问题与证据

上一轮四个20秒运动试次共有200个主测量帧。整帧完成时间取“帧处理完成”和“控制停稳完成”中的较晚值；原始完整完成晚到为198/200，原始记录保留。逐帧分解用于确定感知、规划、保存或控制停稳哪个阶段限制完整完成，分析入口为[计时与停稳分析程序](../../python/analyze_t1_settlement.py)。上一轮数据见[运动尺度分析](../../logs/t1_motion_scale_analysis_v6p1_20261006/report.json)。

原控制器的停稳速度阈值为5毫米/秒，高于上一轮实际运动速度峰值。这个阈值不足以区分本实验的低速运动和停稳；新版以更严格的阈值检验，并保留旧记录的原有含义。[旧控制器](../../python/t1_async_control.py)、[新版停稳配置](../../python/t1_control_settlement.py)

## 2. 冻结设置

| 项目 | 新版预先声明的设置 |
|---|---|
| 身份链路 | 气球专用YOLO、VLX后台复核、源RGB白条属性检查、当前帧关联与复核交接 |
| 飞行阶段 | 固定高度−3米，先零输出8秒，再同场景运动20秒 |
| 主帧周期 | 0.4秒，分别20帧、50帧；初始化单列，未捕获帧保留 |
| 目标指令 | 速度上限0.03米/秒、租约上限0.12秒；当前帧和自身状态有效期保持原设置 |
| 自身状态检查 | 名义周期0.05秒，另报告实际查询间隔 |
| 清零后的反馈 | 仅自身速度及清零时自身位置；反馈期望速度上限0.015米/秒、指令变化率上限0.15米/秒² |
| 采样停稳 | 速度不超过0.5毫米/秒，连续稳定不少于0.10秒，清零后观察不少于0.30秒，至少3个不同仿真状态时刻 |
| 控制停稳时限 | 从指令声明结束时刻起2秒；晚唤醒不会重新起算 |
| 运动尺度标准 | 保留20毫米净XY位移；零输出漂移上限5毫米 |
| 端点 | 主阶段前后已经严格采样停稳的自身状态；如末尾等待停稳，报告实际等待时间 |

具体参数与完整网格由[新版计划校验程序](../../python/t1_settlement_plan_v1.py)在UE启动前检查。源文件、相机设置、YOLO权重及训练记录继续按SHA-256冻结。[准备程序](../../python/prepare_t1_identity_flight_v7.py)

## 3. 两类时间与保留的旧时间

1. **帧处理时间**：采集、RGB保存、YOLO与身份关联、几何估计、规划、控制决策及评价媒体保存的完成时刻，仍与0.4秒帧截止时刻比较。
2. **控制停稳时间**：独立线程在目标租约结束后清零、反馈及获得严格停稳记录的完成时刻，与预先声明的2秒控制停稳时限比较。
3. **原完整完成时间**：继续保留二者最大值和原0.4秒截止点。新版分开报告计时属于协议变化，不能把旧的晚到重新标为及时，也不能声称已经实现0.4秒内完成物理停稳。

忙碌时的新目标建议明确拒绝；无实际指令的帧不生成停稳记录。有实际指令却缺少停稳记录时，完整完成与停稳状态均保留为未知。[计时实现](../../python/t1_control_settlement.py)

## 4. 执行顺序与结论边界

先完成源码及故障回归，再执行新建UE会话中的零输出门控。零输出通过独立证据核查后运行20秒运动先导；先导的严格停稳与身份链路通过后，使用同源版本做独立重复。每次保留原运行器状态、所有计划帧、后台请求、实际指令、自身状态及媒体；落地、解除控制、暂停和新进程地面复核完成后，才关闭拥有的UE进程。

若新版抑制残余运动后净位移不足20毫米，该试次的运动尺度判据判为未达到，不能降低阈值或删去试次。进一步运动验证需要单独冻结适当的持续时长或执行方案。旧版与新版的停稳判据、指令安排与端点定义存在差别；比较用于工程诊断，不能替代第三章正式四方法及YOLO/VLX消融实验。

## 6. 开发试次后的修正与下一条件（2026-10-06）

V7零输出试次的控制停稳与收尾通过，但等待采样停稳造成初始化末帧与主测量首帧之间的图像链间隔超限。20个主帧中14个正确、6个无输出，该试次未用于授权运动验证。[原始分析](../../logs/t1_settlement_zero_analysis_v7_20261006/report.json)、[失败记录](../../logs/t1_strict_settlement_development_20261006/v7_zero_transition_failure.json)

V7P1对已经取得严格停稳证据的零输出建议仍执行原身份门控检查，保留真实零指令而省去新的重复派发。初始化要求当前图像已跟踪且自身状态已经处于这个零保持状态，连续采图进入主测量。新版零输出的20个主帧均正确且净漂移为零。[零保持实现](../../python/t1_async_control_v1p3.py)、[零输出分析](../../logs/t1_settlement_zero_analysis_v7p1_20261006/report.json)

V7P1运动试次的50个主帧均正确，25次非零目标派发，净位移8.0毫米，未达到20毫米尺度。独立核查发现，一部分运动中的样本所附的“前一指令”来自本次状态查询之后派发的反馈指令；原分析保留为失败。V7P2改为记录状态查询之前实际存在的指令，同时在查询后派发非零反馈时撤销本次停稳资格。该修正不改变速度、稳定时长和租约预算。[V7P1运动分析](../../logs/t1_settlement_visible20_analysis_v7p1_20261006/report.json)、[指令顺序修正](../../python/t1_async_control_v1p4.py)

V7P2先重新执行8秒零输出与20秒运动，验证相同场景下的记录修正。随后另行预先冻结**60秒连续可见、150个主帧**的尺度条件，并进行一次同源独立重复。60秒条件保留20毫米净位移、500像素可见目标、0.4秒主帧周期以及原有指令与停稳参数。增加时长是根据20秒试次作出的开发阶段选择；60秒结果不能把20秒未达标试次改判为通过，也不能用于证明相同任务时长下的算法改进。[时长和网格校验](../../python/t1_settlement_plan_v1p2.py)

## 7. 实际清零预算与最终执行记录（2026-10-06）

V7P2的60秒试次保存150个主帧，其中137帧正确、13帧无输出，净位移21.483毫米。一次较慢的帧处理使派发后的实际清零越过原观测截止点，独立集成检查判为失败。其预先准备的重复因此未执行，原运行器通过状态和独立失败判定均保留。[V7P2原始分析](D:/forAirsim/logs/t1_settlement_visible60_analysis_v7p2_20261006/report.json)

V7P3另行冻结派发前的清零预算：在原观测截止点前预留0.12秒，将声明租约结束限制在这个时刻之前。原观测截止点、图像与VLX证据期限、速度及停稳阈值均未放宽。剩余可执行时长不足0.01秒时撤销目标动作；实际清零仍使用原截止点独立核查。这个预算是本轮开发设置，不构成硬实时保证。[预算策略](D:/forAirsim/python/t1_identity_motion_policy_v1p1.py)、[冻结配置检查](D:/forAirsim/python/t1_settlement_plan_v1p3.py)

V7P3先完成8秒零输出，再执行60秒运动及一次同源独立重复。零输出20帧均正确，净漂移为零；两次运动各保存150帧，均关联到指定目标，净位移分别22.972毫米与23.468毫米。所有试次完成独立落地复核后关闭自有UE。这些是受控开发数据，尚未构成正式四方法比较。[最终独立分析](D:/forAirsim/logs/t1_strict_settlement_analysis_final_20261006/report.json)

首个V7P3运动试次的初始审计在两对同主机时间、同仿真状态的读回中选中了较早日志，与控制器记录的查询前实际指令不符。初始失败报告不修改。新版离线审计在全部同值候选中依据实际事件顺序和查询前指令字段确定对应读回，不改状态、时间或任何判据。V7P1的148个错误记录样本仍判失败。[原失败报告](D:/forAirsim/logs/t1_settlement_visible60_analysis_v7p3_20261006/report.json)、[顺序匹配实现](D:/forAirsim/python/t1_stop_receipt_match.py)、[复算后再执行重复的门控记录](D:/forAirsim/logs/t1_strict_settlement_development_20261006/v7p3_60s_ordered_pre_repeat_gate.json)

两次最新运动合计30/300个帧处理晚到，完整完成仍有172/300个晚到。原0.4秒截止点继续保留；分别报告帧处理和采样停稳并未消除这项限制。300帧具有时间关联，独立实验单位是两次UE会话。下一轮需要补真实慢VLX回复、属性干扰和遮挡返回，再单独冻结更大运动尺度、完整几何与正式方法对照。[本轮结果及图表](D:/forAirsim/docs/research-plan-20261004/任务一严格停稳与清零预算验证结果.md)
