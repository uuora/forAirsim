## 4. 第3章：单机单目标感知任务轨迹优化（T1）

### 要做的工作

1. 使用冻结的气球候选检测器，完成指定实例的持续关联、歧义拒识和遮挡后恢复。
2. 接入低频 VLX 复核，处理原图/当前帧、时效、版本和等待代价。
3. 将可见性、身份依据、观测时效和运动代价接入实际规划执行闭环。
4. 完成四方法先导，冻结正式配置，再采集对照与消融；结果按独立回合分析。

### 正文小节与应放内容

| 小节 | 应放内容 |

| 3.3 大模型复核与异步更新 | VLX触发、图文定位、本地关联、过期/超时与新帧确认 |

### 核心对比与消融

| 组别 | 方法或条件 | 比较目的 |
|---|---|---|
| 整体对比 | B0固定跟随；B1距离规划；B2可见性规划；B3身份复核联合规划 | 明确逐步加入质量和身份信息后的系统差异 |
| 检测后端 | 颜色/轮廓、原预训练YOLO、气球专用YOLO；其余实现固定 | 分离检测后端收益与规划收益 |
| 低频复核 | 固定B3、检测器和时序关联，仅关闭/开启VLX | 检验复核带来的身份收益与等待成本 |
| 主要场景 | 无遮挡及侧偏、遮挡、相似干扰、遮挡后重现 | 检验持续有效观测和指定实例保持 |
| 时效场景 | 冻结注入点与序列的处理/响应延迟 | 检验过期拒绝、重观测和慢结果处理 |
| 运动范围 | 先通过实际验收的高度/姿态条件 | 检验已声明三维范围内的方法效果 |

主方法对比统一检测后端、共同可用输入、执行器和预算；消融单列。B0/B1/B2/B3的差异按[任务一详细标准](任务一论文内容与完成标准.md)落实到真实可运行方法。

主要指标：有效可见观测、指定实例保持、回合成功率、最长失锁与重获时间；同时报告航程、运动平滑性、错误目标接近、安全干预、端到端等待和API成本。真值可见性与身份正确分别评分。

## 5. 第4章：双机单目标互补感知轨迹优化（T2）

### 要做的工作

1. 复用第三章的感知状态和执行器，让两机同时观测同一指定目标。
2. 实现带来源、时间与版本的观测共享；明确观测矛盾和过期消息处理。
3. 定义互补视点质量、联合轨迹代价、机间约束和角色交接条件。
4. 验证同步运行与交接，再开展共同场景下的协同对比、模块消融和通信扰动。

### 正文小节与应放内容

| 小节 | 应放内容 |
|---|---|
| 4.1 双机任务建模 | 角色、共享目标、局部/共享信息及协同目标 |
| 4.2 共享观测与状态更新 | 时间/来源/版本、有效性、冲突及丢失消息 |
| 4.3 互补质量与联合轨迹优化 | 冗余/互补定义、目标函数、共同约束及求解流程 |
| 4.4 角色交接与异常恢复 | 交接触发、确认、观测连续性和异常处理 |
| 4.5 实验设计 | 对照、消融、同步验证、遮挡和通信条件 |
| 4.6 结果分析与小结 | 持续观测收益、重复观测、运动/通信代价和局限 |

### 核心实验

- 对比无共享独立规划、固定分工、固定角度互补、动态互补与交接方法；各方法均使用相同两机资源。
- 固定完整方法，分别关闭互补质量项或事件交接，检验两个机制的贡献；尽量复用已有对照，避免重复采集相同方法。
- 场景覆盖单机视点遮挡、交接边界和共同可见；通信延迟/丢包采用少量冻结等级，并报告实际收到的消息。
- 指标优先使用联合有效观测率、同时失锁时长、交接中断与成功率；补充航程、通信量、规划耗时、最小机间距离和安全干预。

## 6. 第5章：连续刷新气球任务的协同规划与学习（T3）

### 要做的工作

1. 跑通有效接触 → 取消旧动作并保持 → 刷新目标 → 新观测 → 重新分配与规划的连续闭环。
2. 冻结接触裁判和整个会话结束条件，完成固定A、轮流和动态分配的规则对比。
3. 在稳定任务环境上建立固定人工奖励MAPPO基线，明确观测、动作、集中训练状态与奖励。
4. 按开题加入模仿预训练和课程训练，完成各模块消融、独立种子测试和未见刷新序列测试。

### 核心对比与消融

| 组别 | 条件 | 要验证什么 |
|---|---|---|
| 规则对比 | 固定A、按轮交替、基于预计到达时间和观测质量的动态分配 | 共同刷新与重规划流程下，动态分配相对固定或轮流分配的收益 |
| 学习基线 | 固定奖励MAPPO | 学习是否优于已验证规则以及需要多少训练成本 |
| 预训练消融 | MAPPO＋模仿预训练 | 初始化知识对学习效率和任务效果的贡献 |
| 课程消融 | MAPPO＋课程训练 | 训练难度安排的贡献 |
| 完整增强 | MAPPO＋模仿预训练＋课程训练 | 两个增强机制的合并效果及可能权衡 |
