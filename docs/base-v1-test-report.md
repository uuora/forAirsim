# AirSim 双无人机基础版测试报告

日期：2026-09-08

## 测试目标

验证固定气球、真实坐标、机体接触判定、DroneA 首次尝试、DroneB 单次补位以及失败后安全停止和复位流程。

## 测试原理

命中判定不使用距离或视觉框，而使用 AirSim 本轮产生的新碰撞事件。事件必须满足 `has_collided=true`、时间戳大于上一条记录，并且对象名精确等于 `BalloonTarget`。任务顺序由状态机限制：A 漏击且通道清空后才能派发 B；A 命中后没有进入 B 的合法转换。双机安全由每次遥测中的实际间距和待命点漂移检查。

## 结论与边界

基础版已满足固定场景的功能测试：A 命中时任务结束，A 漏击并让路后 B 自动接替；错误目标、旧碰撞和非目标碰撞不会计分；目标缺失会在起飞前停止；成功和失败均留下可追溯日志。

本报告不证明动态目标、视觉闭环、通用避障或真实网络故障恢复能力。主动关闭 UE 的断连测试可能使空中飞机失去控制，因此不作为进入批量固定场景验证的前置条件。通信异常的离线状态处理已覆盖，真实断连留到专门的故障注入环境测试。
