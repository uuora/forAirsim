- `logs/platform_validation/after_restart.json`

验收阈值：采样漂移小于 5 厘米；原点高出甲板 0 至 0.6 米；在平台平面中心各轴 5.5 米范围内；落地状态；存在已知平台构件的历史接触记录；重启位置差小于 5 厘米。所有位置必须为有限数值。

本次不包含飞行后着陆、极端海况、长时间运行或水动力测试。平台的理论波峰净空沿用当前材质公式下的 2.17 米下界。
