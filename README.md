# 无人机控制仿真实验

**平时只打开：[打开轨迹实验面板.cmd](打开轨迹实验面板.cmd)。**

另一台已能运行原03环境的电脑：拉取`codex/hermite-disturbance`分支后，运行`powershell -ExecutionPolicy Bypass -File scripts/setup-control-reproduction.ps1`补齐冻结方案、固定ABOM网络与本轮证据；不重装UE、不自动飞行。详见[跨电脑同步步骤](docs/使用说明/跨电脑复现_20261101.md)。

需要**边飞边规划**时，在准备点设置区点击“连续飞行 · 后台规划（协议16开发版）”，切换到新的空闲工作台，再选择方法、起点、种子和时长，点击“开始连续飞行”。后台只使用当前/下一目标，在固定的未来时刻接入通过检查的曲线；迟到或无改进时继续原参考。普通六组的固定路线实验入口仍保留。

在线模式点“本次轨迹与数据图”看同步误差、速度与搜索采用记录；点“返回记录库 / 勾选对比”进入数据页，筛选“协议16·连续在线”。不同协议和不同源码条件不混排。详细说明：[连续在线规划](docs/使用说明/连续飞行后台规划_协议16.md)。

完整流程与通过标准见[本轮实验步骤](docs/使用说明/完整控制实验_步骤与评判标准_20261101.md)。本轮固定路线12次、在线机制24次的[统一结果入口](reports/control_full_flow_20261101_v1/analysis/index.html)在全部运行和独立重算结束后生成；逐项运行进度与原始目录保存在`reports/control_full_flow_20261101_v1/campaign.json`。日常六方法菜单不自动启动这套研究批量。

1. 在“实验控制”页启动仿真，选择任务组和方法，修改准备点 X / Y / 高度及共同航点。
2. 点击“到准备点 → 规划 → 飞行”：先真实起飞、到准备点停稳，再悬停计算所选方法，最后执行参考。启动、切换方法和“应用任务设置”不会自动飞行或规划。
3. 跑六种方法时，点击“勾选批量运行”。勾选一个实验组跑6次，两个组跑12次；每项分别到准备点后重新规划。
4. Qt默认显示整条任务的三维图，可点“展开视图”放大绘图区；“俯视等比例 / 正视等比例”可辅助检查。绿虚线是参考，亮紫线是实测；S方块为曲线起点，W小点保留已经过的中途点，E为终点。
5. 数据到“数据管理”找；图到“图表对比”看。点“六种方法改了什么 / 通过标准”或“数据怎么读”查看算法差异、单位和门槛。
6. 不再需要显示的记录可“收起到历史”；需要时勾选“显示历史 / 开发资料”找回。

[03_三维双目标控制.cmd](03_三维双目标控制.cmd)保留作原框架对照，通常不需要同时打开。

## 文件在哪里

| 位置 | 用途 |
|---|---|
| 面板：数据管理 | 当前飞行、参考方案与对比结果；日常查数据从这里进入 |
| 面板：图表对比 | 轨迹、误差、速度/指令与指标图；支持导出 |
| logs | 原始状态、指令、失败和中断记录，由程序管理 |
| reports | 方案与生成结果，由程序管理 |
| 历史工具 | 以前的识别、地图维护及重复快捷入口 |
| docs/使用说明 | 详细操作手册 |
| experiment_data | 数据索引、历史分类与可恢复归档清单 |
| python、scripts、configs、external、.venv等 | 代码及运行依赖，运行时需要 |

当前默认协议15：可改准备点、三点路线、两组各六方法。ABOM改的是参考轨迹搜索，底层跟踪控制器统一；改进候选尚无整体更优证据。协议14旧记录保留，不能与15混排。

UE首次显示用任务全景，同一连接下再次运行会保留手动缩放、中心、角度及跟随状态。需要跟随或聚焦时，使用UE左上角按钮；更改任务后可手动点“整体场景”重新取景。中途点“已经过”是显示标记，是否满足控制门槛仍以数据中的过点判据为准。

Qt地图右上角可切换深色/浅色外观并记住选择。地图采用带层次的坐标参考平台、米制网格、轨迹投影和避让标签，保留原四旋翼；平台为显示参考面。

详细说明：[控制实验](docs/使用说明/实时六组实验_运行说明.md) · [数据与图表](docs/使用说明/数据管理与图表_使用说明.md)。

项目其他阶段的材料见[历史项目说明](docs/项目历史说明.md)，旧原始实验仍保留。
